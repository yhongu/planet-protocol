# 02. 生命と文明

> 科学的な根拠と 1990 年からの改訂点は [06-science-basis.md](06-science-basis.md) §3, §6 を参照。

## 1. 設計の要点

SimEarth の生命は「バイオームのペンキ」に近く、進化が装飾的だった。本作は生命を**環境ドライバの一級市民**として扱う。生命は気候を変え、気候は生命を選別する。プレイヤーは種を直接デザインせず、**環境圧をかける**ことで進化の方向を操作する。

そして最も重要な設計上の決定:

> **生命は惑星を安定させるとは限らない。**

大量絶滅の多く、大酸化事変、後期デボン紀の海洋無酸素化は、いずれも**生命自身が引き起こした**。これらは災害イベントとしてハードコードせず、**通常の生態系機構から自然発生させる**。

## 1.5 実装上の絶対規則: 物理単位で書く ★

**生命はセルの上に乗るので、解像度依存のバグが最も出やすい層である。**

フェーズ1 でこの種のバグを 3 回踏んだ（`docs/04-8.8`）。生命はもっと多い。

| 量 | ❌ 素朴な書き方 | ✅ 正しい書き方 |
|---|---|---|
| 分散 | `dispersal` セル/ティック | `dispersalKmPerYr`、セル幅から係数を導く |
| 種分化 | セルあたりの確率 | `speciationPerAreaPerYear` × `cellArea` × `dt` |
| 生息域 | 「N セル以上」 | 「N km² 以上」（面積積分で判定） |
| 個体数 | セルあたりの生物量 | `kg/m²` × `cellArea` |
| 競合の範囲 | 「隣接 8 セル」 | 相互作用距離 [km] からセル数を導く |
| 絶滅判定 | 「M セル以下」 | 総個体数（面積積分）が閾値以下 |

**セル幅は緯度で変わる**（`2πR cos φ / W`）。東西方向の量は緯度ごとのセル幅を使う。

`tests/resolution.test.ts` が不変条件として固定している。
M5 ではここに **クレード数・総バイオマス・主要なケイパビリティの獲得年代**を追加する。

## 1.6 教科書にするか、開かれた進化にするか ★中心的な設計判断

シムアース系は**教科書どおり**だった。三葉虫 → 魚 → 両生類 → 爬虫類 → 哺乳類 → 人類、という
地球の実史をなぞる固定の梯子があり、**イカっぽい哺乳類は絶対に出てこない**。
既知の生物名を引く実装だから、出しようがない。

一方で「全部を開かれた進化としてシミュレートする」は破綻する。計算量もだが、
それ以上に**出力が読めなくなる**（何を見せられているのか分からない生物が並ぶだけになる）。

**第三の道を採る。生物を模擬しない。能力と体制を模擬し、記述を生成する。**

### 根拠となる生物学: 機能は収斂する、系統は収斂しない 🟢

| 収斂する（何度でも出る） | 収斂しない（一度きり／偶然） |
|---|---|
| 目（40 回以上）| 真核生物（**45 億年で 1 回**）|
| 動力飛行（4 回）| 脊椎動物という特定の体制 |
| 反響定位（2 回）| 節足動物という特定の体制 |
| C4 光合成（60 回以上）| 霊長類 |
| 多細胞性（**25 回以上**）| |

Gould（偶然が支配する）と Conway Morris（収斂が支配する）の論争は、
**レイヤーが違うだけで両方正しい**というのが現在の総合。

実験室での決定的な証拠が **Lenski の長期進化実験** 🟢。
同一の大腸菌 12 系統を同一条件で 5 万世代以上走らせた結果:

- 適応度の上昇は **12 系統すべてで収斂した**
- しかしクエン酸利用能（Cit+）は **12 系統中 1 系統でしか出現しなかった**
- しかも、それ以前に特定の「素地となる変異」が入っていた系統でしか出ない
  (Blount, Borland & Lenski 2008)

**同じ初期条件・同じ環境でも履歴依存で分岐する。** これがそのまま設計原理になる。

### 設計への落とし込み

| 生物学の事実 | 実装 |
|---|---|
| 機能は収斂、系統は収斂しない | **能力ビットフラグ**（§2.1）。誰が獲得するかは毎回違う |
| 真核化は 1 回 | **ハードステップ**（§2.1b）。起きない惑星があってよい |
| Cit+ は素地依存 | **前提能力を持つクレードしか次を獲得できない**（§2.1b） |
| 絶滅が盤面をリセット | 優占者ほど強く被害 → 空いた地位を別系統が埋める（§2.7） |
| 体制は多様 | **ボディプランの軸**（§2.0b）。「内骨格を持つ 8 腕の胎生水棲動物」が表現できる |

### 名前は引かない。生成する ★

イカっぽい哺乳類が出せない原因は、既知の生物名を引いているからである。
**形質の組み合わせから記述を生成すれば、そもそも「イカ」も「哺乳類」も要らない。**

```
体制 { 内骨格, 左右相称, 8 本の腕状付属肢 }
能力 { 胎生, 恒温性, 高神経密度, 水生, 社会性 }
      ↓
「内骨格をもつ 8 腕の胎生水棲動物。恒温性と高度な社会性をもつ」
```

プレイヤーには**それが何であるか**が伝わる。地球の生物名に対応づける必要がない。
地球で見たことのある組み合わせなら「イカに似た」「哺乳類に似た」という
**比喩を添えるだけ**にする（分類ではなく比喩であることを明示する）。

### 地球の歴史は「レール」ではなく「比較トラック」にする ★

教科書性を完全に捨てると、プレイヤーは自分の惑星が変なのか普通なのか分からない。
そこで**地球の実際の年表を並走表示する**。

```
あなたの惑星   多細胞  ●━━━━━━━━━━━━━━━━━━━━━━━ 3.1 Ga
地球（参考）           ━━━━━━━━━━━━━━━●━━━━━━━ 0.8 Ga  ← 23億年早い
```

**逸脱そのものがコンテンツになる。** 地球をなぞらせるのではなく、
地球との差分を読ませる。これなら教科書的な読みやすさと、
毎回違う結果の両立ができる。

### 計算量への答え: 追跡するクレード数を上限で切る

全部をシミュレートすると破綻するので、

- **能動的に追跡するクレードは 20〜50 程度**に制限する
- それ未満の多様性は**バイオーム単位のスカラー**（総バイオマス + 多様度指数）に丸める
- 追跡クレードは「バイオマスが閾値を超えた」「能力を新規獲得した」ものが昇格し、
  落ちたものは背景に降格する

これは実際のマクロ進化研究が種ではなく**科・目の単位**で議論するのと同じ発想であり、
手抜きではなく妥当な粗視化である。§1.5 の物理単位規則をここにも適用する
（クレード数は解像度から独立させ、「バイオマス何 kg/m² 以上」で決める）。

## 2. クレード（系統）モデル

### 2.0b ボディプラン（体制）の軸 ★

能力フラグだけでは「イカっぽい哺乳類」は表現できない。**体制を直交する軸に分解する。**

| 軸 | 取りうる値 | 効く先 |
|---|---|---|
| 対称性 | 放射 / 左右 / 非対称 | 運動性、感覚器の配置 |
| 骨格 | なし / 外骨格 / 内骨格 / 水力学的 | 上陸のしやすさ、最大体サイズ |
| 体節 | なし / あり | 付属肢の反復、再生能力 |
| 付属肢の数 | 0, 2, 4, 6, 8, 多数 | 操作能力、移動様式 |
| 呼吸 | 拡散 / 鰓 / 肺 / 気管 | 上陸、最大代謝速度 |
| 繁殖 | 産卵 / 胎生 / 出芽 | 世代時間、親の投資 |
| 循環 | なし / 開放 / 閉鎖 | 最大体サイズ、活動度 |

**地球の分類群はこの空間の特定の点に過ぎない。** 空いている点が大量にある。

例: 内骨格 × 8 付属肢 × 閉鎖循環 × 胎生 は地球に存在しないが、
**個々の要素はすべて地球で進化している**ので、禁止する理由がない。

体制は**ほぼ変わらない**（進化の初期に固定され、後から変えるコストが極めて高い）。
これが「系統は収斂しない」の実装である。能力は何度でも獲得されるが、
体制は分岐したら戻らない。

### 2.1b ハードステップと履歴依存 ★

すべての能力を同じ確率で扱ってはいけない。**桁で違う。**

| 種類 | 地球での回数 | 実装 |
|---|---|---|
| ありふれた獲得 | 数十回 | 通常の獲得確率 |
| **ハードステップ** | **1 回** | 基準確率を 3〜4 桁下げる。**起きない惑星があってよい** |

ハードステップに指定するもの 🟢:

- **真核化**（細胞内共生）— 45 億年で 1 回。すべての真核生物が単一の共生の子孫
  （Spang et al. 2015 のロキアーキオータ、Imachi et al. 2020 の *Prometheoarchaeum* 培養）
- 酸素発生型光合成 — 1 回（シアノバクテリア）
- 象徴的行動 — 1 回

**履歴依存（Lenski の Cit+）の実装**:

```
獲得可能 = 前提能力をすべて持つ && 前提【体制】を満たす
P(獲得)  = base × Π(環境修正子) × f(そのクレードが前提を得てからの経過時間)
```

前提を満たしていないクレードは、環境がどれだけ好条件でも獲得できない。
**「たまたま先に別の能力を得ていた系統だけが次に進める」**という構造を作る。
これがリプレイのたびに違う勝者を生む。

### 2.0 前生命化学 —— 生命が生まれるまで ★2026-08-31 実装

**実装: `src/sim/prebiotic.ts`。** 生命の起源を「時刻で起きるイベント」ではなく
**惑星の状態の帰結**にする。いつ・どこで・どの経路で生まれるかが惑星ごとに変わる。

#### 化学の階段

原料の供給 → **濃縮** → 重合 → 自己複製。
アミノ酸（→ペプチド）と核酸塩基（→RNA）は 1〜3 を**並走**し、4 で合流する
（RNA ワールド → RNP ワールド）。ミラー実験でアミノ酸ができても RNA には
ならない、というのがまさにここ。**律速は 2 の濃縮である。**

| 段 | モデルでの実装 | 惑星のどの量が効くか |
|---|---|---|
| 1. 供給 | 熱水の還元 + 紫外線光化学 + 隕石供給 | `ventFlux`・日射・O₂（オゾン）・時間 |
| 2. **濃縮** | 3 つの機構の倍率（最大値は揃えてある） | 陸の割合・潮汐・火山活動・氷 |
| 3. 重合 | 濃度の**2 乗**に比例（濃縮が 10 倍なら 100 倍） | 温度の窓（45±35℃） |
| 4. 自己複製 | **ハードステップの抽選**（§2.1b） | 上の全部 |

#### 濃縮の 3 機構 —— ここで §2.8 の起源地が【創発する】

| 機構 | 場所 | 止まる条件 |
|---|---|---|
| 潮間帯の乾湿サイクル | 陸の割合が 0.5 のセル（＝海岸線） | 氷に覆われる |
| 温泉の乾湿サイクル | 陸 × 火山活動 | 氷に覆われる |
| 噴出孔のチムニーの微細孔 | 海底の熱水域 | **止まらない（海底なので）** |

**3 つの最大倍率は揃えてある。** 揃えないと機構の強弱だけで勝敗が決まり、
惑星の性質で分岐しなくなる（実測: 沿岸だけ強くしたら全時代で沿岸 95%）。
揃えたうえで「**どこにその場があるか**」を惑星に決めさせる。
氷に覆われた惑星では噴出孔だけが残る。

#### 点火はハードステップ（§2.1b）

```
λ = originHazard × Σ_i (オリゴマー濃度_i / 基準濃度)² · 面積比_i × 衝突による挫折
P(このステップで起きる) = 1 − exp(−λ·dt)
起源のセルは λ の重みに比例して抽選する
```

★**閾値にしてはいけない。** 加水分解の時定数は 500 年なので、
化学は地質時間から見て常に準定常になる。閾値だと**条件が揃った瞬間
（実測 21Myr）に点火する**。化学が決めるのは「待ち時間の期待値」の方。

★**衝突による挫折（impact frustration）**。冥王代の巨大衝突は海を蒸発させ、
生まれた生命を全滅させる（Maher & Stevenson 1988）。
無いと**まだマグマオーシャンに近い 36Myr で生命が生まれる**。

#### 実測（64x32・8 seed・既定の惑星）

| seed | 起源 [Myr] | 経路 |
|---|---|---|
| audit | 400 | 熱水 |
| gaia-77 | 641 | 熱水 |
| terra-3 | 594 | 熱水 |
| res-check | 266 | **潮間帯** |
| nova-9 | 305 | 熱水 |
| hadean-01 | 354 | 熱水 |
| mira-2 | 345 | **潮間帯** |
| kepler-5 | 449 | 熱水 |

中央値 377Myr（地球は形成後 500〜700Myr = 3.8〜4.0Ga）。
経路は 8 本中 2 本が潮間帯。**同じ設定でも seed で年代も経路も変わる。**

#### 実装で踏んだ罠（`CLAUDE.md` の作法がそのまま効いた）

1. **単位**: `ventFlux` は W/m² = J/(s·m²)。秒を掛け忘れて熱水の寄与が
   3156 万分の 1 になり、隕石供給だけが効いて 100Myr で枯れた
2. **海は混ざる**: 刻み 400kyr に対し海洋の混合は約 1000 年。
   セルごとに溜めたら線状に集中する熱水が局所濃度で圧勝し、
   **6 seed とも 100% 熱水**になった。海のモノマーは**全球ひとつの溜め**にする
3. **収支を閉じる**: 重合を海の溜めから引いていなかったので、
   オリゴマー濃度が 1e11 mol/m² という非物理な値になった
4. **同じ量を 2 か所で計算しない**: 経路の分類で潮汐の係数を掛け忘れ、
   ハザードの取り分が熱水 40%・沿岸 60% なのに**8 seed すべてが熱水**になった
5. **重みに比例して抽選する**: 「最大のセル」に固定すると、
   取り分が 40% しかない機構が常に勝つ

### 2.8 生命の起源地は分岐する 🔴 ★未決着だからこそ機構になる

「海で生まれる」は決まっていない。**現在も決着していない。**

| 説 | 根拠 | 確度 |
|---|---|---|
| アルカリ熱水噴出孔 | LUCA の化学浸透（プロトン勾配）駆動の代謝が、ロストシティ型噴出孔の**天然のプロトン勾配**と対応。Wood–Ljungdahl 経路が地球化学的に再現できる（Russell & Martin） | 🟡 |
| **陸上の地熱地帯** | 細胞内の **K⁺/Na⁺ 比が海水ではなく地熱凝縮水と一致する**（Mulkidjanian et al. 2012）。かなり強い論拠 | 🟡 |
| 温泉の乾湿サイクル | 脂質小胞の形成と重合には**乾燥サイクルが必要**で外洋では得られない（Deamer & Damer） | 🟡 |
| 浅い地表の池 | シアノスルフィド化学は**紫外線と高濃度の原料**を要する（Sutherland, Powner） | 🟡 |
| 空中 | ❌ 濃縮も蓄積もできない。エアロゾルを**反応場**とする説はあるが起源にはならない | 🟢（否定） |

**実装**: 惑星の状態（陸面積、地熱流量、潮汐、紫外線量、海洋 pH）から起源地を分岐させ、
それが**下流の代謝を長く縛る**。

- 噴出孔起源 → 化学合成独立栄養から始まる。光合成の獲得が遅れる
- 地表起源 → 最初から光に曝される。光合成が早い。ただし紫外線耐性が必須
- 温泉起源 → 乾燥耐性を最初から持つ。上陸が早い

同じ惑星でも起源地が違えば全く違う生物圏になる。**しかもこれは科学的に正当な不確実性である。**

### 2.9 知能と技術文明は別物 ★

頭足類はすでに大きな脳を持つ（タコで約 5 億ニューロン ≒ イヌ）。
獲得していないのは知能そのものではなく、**技術文明の前提条件**である 🟢。

| 前提 | 頭足類 | 効く理由 |
|---|---|---|
| 大きな脳 | ✅ | |
| 器用な操作器官 | ✅ | |
| **寿命** | ❌ 多くが 1〜2 年 | 世代を超えた文化伝達ができない |
| **社会性** | ❌ ほぼ単独性 | 同上 |
| **火** | ❌ 水中では不可能 | 冶金・製陶が原理的に不可能 |
| 剛性骨格 | ❌ | てこが使えない |

したがって `Cap.Symbolic`（知能）と「技術文明の成立」を**分離する**。
知能は水中でも出るが、**火を使う文明は陸上に限る**。

逆に言えば、**寿命が延び・社会性を獲得し・上陸した頭足類型の体制**は
技術文明に到達しうる。これはフィクションではなく、
どの前提が欠けているかを列挙した結果として出てくる。

「目が異常に発達した系統」「寿命が桁で延びた系統」も同様に、
形質を連続値で持たせておけば**自然に出る**。地球で起きなかったのは
禁止されていたからではなく、**その系統がその選択圧に晒されなかったから**である。

### 2.10 無機物生命 🔴

**ケイ素生命に限れば、ほぼフィクション** 🟢。理由は化学的に明確:

- Si–Si 結合は C–C より弱く、長鎖が安定しない
- **SiO₂ は固体**。CO₂ のように気体で循環できないので、炭素循環に相当する物質循環が作れない
- 官能基の多様性が桁で足りない

ただし「無機物生命 = ケイ素生命」ではない。真面目な提案は存在する 🔴:

- **粘土鉱物起源説**（Cairns-Smith 1966, 1982）: 粘土結晶の欠陥が最初の複製子で、
  後に有機物が「乗っ取った」。**否定もされていないが実証もされていない**
- **無機化学細胞 iCHELL**（Cronin）: ポリオキソメタレートの膜。自己組織化はするが生きてはいない
- **Assembly theory**（Cronin & Walker 2023）: 化学種に依らず「生命らしい複雑さ」を測る枠組み。論争中

**方針**: 炭素＋水以外が不可能だと証明されてはいないが、
経路が示せているのは炭素＋水だけ。**極めて稀な分岐**として置き、
出たときは 🔴 であることを明示する。「あり得る」と「確からしい」を混同させない。



種を 1 つずつ持つのは重すぎる。**クレード（系統枝）**を単位にする。同時に存在するクレードは 30〜60 程度。

```ts
interface Clade {
  id: number
  /** 通常の分岐なら親は 1 つ。内部共生・交雑では 2 つ以上（§2.4） */
  parentIds: number[]
  originKind: 'speciation' | 'endosymbiosis' | 'hybridization'
  bornYear: number
  diedYear: number | null
  name: string              // 自動生成（§2.6）
  traits: Float32Array      // 形質ベクトル（§2.2）
  capabilities: number      // ビットフラグ（§2.3）
  biomassIndex: number
}
```

### 2.1 「はしご」を廃止する ★1990年からの最大の改訂

**旧設計（誤り）**: `PROKARYOTE → EUKARYOTE → MULTICELL → TERRESTRIAL → SAPIENT` という、全生物圏で共有される一本の階段。O₂ 濃度が各段のゲート。

**なぜ誤りか**:
- 多細胞性は**独立に 25 回以上進化した**。単一の「多細胞グレード」は存在しない。
- **酸素は動物進化の律速ではなかった可能性が高い**。カイメンは現代の 0.5–4% の酸素で生きられる (Mills et al. 2014)。硬い閾値ゲートは支持されない。
- 人類進化も braided stream であり、はしごではない (Scerri et al. 2018)。

**新設計**: グレードを廃し、**ケイパビリティ（獲得形質のビットフラグ）**にする。

```ts
const enum Cap {
  Photosynthesis   = 1 << 0,   // 酸素発生型光合成
  Aerobic          = 1 << 1,   // 好気呼吸
  Mitochondrion    = 1 << 2,   // 内部共生由来（§2.4）
  Plastid          = 1 << 3,   // 同上
  Multicellular    = 1 << 4,   // 何度でも独立に獲得される
  Motile           = 1 << 5,
  Predatory        = 1 << 6,   // 捕食 — 軍拡競走の起点
  Skeletal         = 1 << 7,   // 骨格・殻（炭酸塩リザーバに効く）
  Terrestrial      = 1 << 8,
  Vascular         = 1 << 9,   // 維管束 — 風化促進と富栄養化の両方の元凶
  Lignin           = 1 << 10,  // 難分解性有機物 — 炭素隔離
  Endothermic      = 1 << 11,
  Bioturbation     = 1 << 12,  // 生物擾乱 — 堆積物の酸化、リン再循環を変える
  SulfateReducing  = 1 << 13,  // ★メデア機構: 硫化水素生成
  NitrogenFixing   = 1 << 14,
  Social           = 1 << 15,
  Symbolic         = 1 << 16,  // 象徴的行動 → 文明の前提
}
```

**獲得規則**:

- 各ケイパビリティは**獲得確率**を持ち、環境変数はその確率の**修正子**であって、閾値ゲートではない。
  ```
  P(acquire Multicellular) = base × f(O2) × f(捕食圧) × f(クレードの個体数) × f(経過時間)
  ```
- したがって **酸素が低くても、時間さえあれば多細胞は出る**（ただし確率は低い）。逆に酸素が高くても出ないこともある。1990 年的な決定論を廃す。
- **同じケイパビリティが複数のクレードで独立に獲得されてよい。** 系統樹に同じ印が何度も付く。これが正しい。
- 一部は**失われうる**（寄生生物における運動性の喪失など）。

### 2.2 形質ベクトル

| 形質 | 効果 |
|---|---|
| `tempOptimum` / `tempTolerance` | 適応度の温度ガウス窓の中心と幅 |
| `aridityTolerance` | 乾燥耐性 |
| `oxygenDemand` | 高いほど活発だが低 O₂ で死ぬ |

| `ccnProduction` | **雲凝結核の生産**。雲アルベドを上げる。CLAW は否定されたが CCN の生物起源は実在（§01-3.3） |

### 2.2b ゲノム —— 形質を記号列として持つ ★2026-08-31 実装

**実装: `src/sim/genome.ts` / `src/sim/life.ts`。**

#### なぜ記号列にするのか

§1.6 が中心的な設計判断として「**機能は収斂する、系統は収斂しない**」を掲げている。
ところが形質が連続値のベクトルだけだと、**2 つのクレードが同じ能力を持ったとき
それが収斂なのか共通祖先由来なのかを区別する手段が無い。**

| 見えるもの | 意味 |
|---|---|
| 同じ能力・**違う由来** | 収斂進化（目は 40 回以上独立に進化した） |
| 同じ能力・**同じ由来** | 相同（共通祖先から受け継いだ） |
| 他系統の**断片が入っている** | 水平伝播・内部共生（§2.4 の系統樹の合流） |

**ゲノムの可視化は飾りではなく、このモデルが主張したい生物学を
表示できる唯一の方法である。**

#### 物理を壊さないための約束

```
ゲノム（記号列） --decode--> 形質ベクトル（§2.2・既存） --> 適応度・個体数
```

**形質ベクトルを置き換えるのではなく、その【デコード元】にする。**
下流（適応度・生物地球化学）は形質ベクトルしか見ないので、
ここを足しても既存の設計と較正は無傷。

#### 表現

遺伝子 1 個 = `{ 種類, 強さ, 由来 }`。ゲノムはその並び（3 本の並列配列）。

| 欄 | 内容 |
|---|---|
| 種類 `kind` | どの形質・能力に効くか（連続形質 16 + 能力ビット 9） |
| 強さ `value` | 0..255。**同じ種類が複数あれば足し合わさる**（遺伝子量効果） |
| 由来 `origin` | その遺伝子が最初に生まれた出来事の id。**収斂と相同を分けるのはこれだけ** |

帯として描けば **色＝種類・明るさ＝強さ・縁＝由来**になる。

デコードの飽和は `1 − exp(−x)` で行う。**線形にクランプしてはいけない**
（勾配が 0 になり、重複したぶんの選択が働かなくなる）。

#### 変異

| 操作 | 由来 id | 意味 |
|---|---|---|
| 点変異 | そのまま | 強さが動く |
| **重複** | **引き継ぐ** | 遺伝子量が増える。**新機能の材料** |
| 欠失 | — | 失う |
| **新機能化** | **新しく振る** | 重複したコピーの種類が変わる。**新しい能力の唯一の入口** |
| **合流（splice）** | **提供者のものを保つ** | 水平伝播・内部共生。取り込んだ側に相手の由来が残る |

**新機能化で由来 id を新しく振るのが要点。** 別系統で独立に起きれば
同じ能力でも由来が違うので、**収斂として表示できる。**

#### 起源の経路が最初の代謝を縛る（§2.8 との接続）

| 起源 | LUCA が持つもの |
|---|---|
| 熱水 | 高温適応・酸素毒性耐性。**光合成を持たない** |
| 温泉 | 乾燥耐性 + **陸耐性の能力**（上陸が早い） |
| 潮間帯 | 最初から光合成の芽を持つ |

実測（seed audit）: 起源 400Myr・熱水 → LUCA は遺伝子 5 個・最適温度 0.578・光合成 0。

#### まだ無いもの（次の一枚）

個体数の力学（§2.3）・分岐と絶滅（§2.5・2.7）・ハードステップの獲得（§2.1b）・
生物地球化学への作用（§3）。いまの `life.ts` は
**「起源からゲノムまでを一本つないだ」だけ**である。

### 2.3 適応度と個体数

セル `c` におけるクレード `k` の適応度:

```
fitness(k, c) = Π over factors  gauss(env, trait)  ×  nutrientLimitation(c, k)
```

主要因子（すべて 0..1 の乗算）:
- 温度: `exp(−((T_c − opt_k)² / (2·tol_k²)))`
- 乾燥: `f(soilMoisture_c, aridityTolerance_k)`
- 酸素: `clamp(O2 / oxygenDemand_k, 0, 1) × (1 − toxicity(O2, oxygenToxicity_k))`
- 光: 光合成クレードのみ、緯度と雲量から
- **栄養**: Liebig の最小律 — `min(P可用性/P要求, N可用性/N要求)`
- 生息基質: 海洋クレードは陸で 0、陸上クレードは海で 0

個体数はロジスティック成長 + 拡散 + 競合:

```
dB_k/dt = r_k · B_k · (1 − Σ_j (a_kj · B_j) / K_c)  +  D_k · ∇²B_k  −  predation
```

`a_kj` はニッチ重複度（形質ベクトルの距離から導出）。形質が近いクレードほど激しく競合する。これでニッチ分割による共存が自然に起こる。

`Predatory` を持つクレードは他クレードのバイオマスを消費する。**捕食の登場が軍拡競走を起こし、骨格・運動性・大型化を駆動する** — これがカンブリア爆発の現代的な説明の一つ（酸素説の代替）。

### 2.3b 実装（2026-08-31）—— 400kyr の刻みでは生態は【平衡】である

**実装: `src/sim/life.ts`。**

★**ロジスティック方程式を積分してはいけない。** 増殖の時定数は年〜千年、
シムの刻みは 400kyr。**その差は 400 倍以上**なので生態は常に平衡にある
（前生命化学で海が完全に混ざるのと同じ理屈）。解くのは平衡配分:

```
そのセルの埋まり具合 = K(c) × max_k f_k
クレード k の取り分  = f_k^γ / Σ_j f_j^γ
```

同じ理由で**拡散も刻みでは効かない**（400kyr あれば地球を何周もする）。
障壁は拡散ではなく**基質**で表現する（海のクレードは陸で適応度 0）。

環境収容力 K は `phosphateSupply` [mol-P/m²/yr] から作る。
**長期の生物圏の天井を決めるのはリン**（§3.3）。造山が止まればリンが減り
生物圏が頭打ちになる —— M4 との結合点。

#### ★選択が無いと生命は絶滅する

クレードは「個体」ではなく**集団**なので、平均形質は適応度の勾配を登る。
最初これを入れずにただ変異させたら、**変異がランダムウォークになり
致死的な組み合わせに迷い込んで 800Myr までに全滅した**（実測）。

候補を数個作って**実際に取れるバイオマス**が最大のものを採る。
中立に近い変異も通す（そうしないと遺伝子の重複のような
「いまは無駄だが後で効く」変異が一切残らない）。

★**評価には競争を入れること。** 生の適応度で評価すると**全クレードが同じ山を
登って同じ形質に収束する**（実測: 16 クレードが全部バイオマス 0.0176・
分布 51.7%）。取り分で評価すれば、他が強い場所では取り分が減るので
**空いたニッチへ動く力**が働く。

★**すべての因子を 0..1 の掛け算にすること。** 栄養を `/ 要求` と割って 1 を
超えさせたら、クランプで**全クレードの適応度が 1 に張り付いて区別が消えた**。
リービッヒの最小律は「制限」であって「増幅」ではない。

#### 実測（64x32・seed audit・全史）

| 年代 | クレード | 総バイオマス | 気温 |
|---|---|---|---|
| 800Myr | 2 | 0.078 | -5.3℃ |
| 1600Myr | 4 | 0.114 | -1.0℃ |
| 2800Myr | 15 | 0.198 | 5.9℃ |
| 4400Myr | 16（上限） | 0.297 | 18.9℃ |

**惑星が暖まるとバイオマスが増える**（0.078 → 0.30）。
クレードは上限 16 に達し、バイオマスの取り分に差が出る（0.0102〜0.0177）。

#### まだ弱いところ

- **空間のニッチ分割が弱い**（分布がどのクレードも 49〜53% でほぼ同じ）
- 上限に達した後の**入れ替わりが無い**（絶滅が起きない）
- 捕食（§2.3 の predation 項）、系統樹の合流（§2.4）、
  ハードステップの獲得（§2.1b）は未実装

### 2.4 系統樹の合流 (reticulation) ★

**真核生物はアーキアの内部から、内部共生によって誕生した**（二ドメイン説、アスガルドアーキア）。これは分岐ではなく**融合**である。

```ts
// 内部共生: 宿主クレード + 共生者クレード → 新クレード
function endosymbiosis(host: Clade, symbiont: Clade): Clade {
  return {
    parentIds: [host.id, symbiont.id],
    originKind: 'endosymbiosis',
    traits: blend(host.traits, symbiont.traits),          // 形質の合成
    capabilities: host.capabilities | symbiont.capabilities, // 能力の和集合
    ...
  }
}
```

**発生条件**: 同一セルに共存し、一方が `Predatory`（捕食＝取り込みの前提）、一方が有用な代謝（`Aerobic` や `Photosynthesis`）を持ち、長期間共存していること。低確率。

**帰結**:
- ミトコンドリア獲得（好気性アルファプロテオバクテリアの取り込み）
- 葉緑体獲得（シアノバクテリアの取り込み）
- 二次共生（葉緑体を持つ真核生物のさらなる取り込み）
- 交雑（`hybridization`）— 近縁クレード間。**人類の braided stream もこれで表現する**

系統樹 UI（§03-5.4）に**分岐だけでなく合流の線が描かれる**。分岐しかない系統樹はもう古い。これは視覚的にも強い差別化になる。

### 2.5 分岐（適応放散）

Evolution ティック（10,000 年ごと）で、各クレードについて:

1. **分岐機会の判定** — 個体数十分（`B > B_min`）で、かつ**適応度は低いが到達可能な隣接セル**を持つか？ = 未開拓ニッチに接している。
2. 満たすなら確率 `p_speciate` で娘クレードを生成。
3. 娘の形質 = 親の形質 + ガウスノイズ。**未開拓ニッチの方向にバイアス**をかける。
4. 娘が親と同じニッチに落ちたら競合で即座に消える → 意味のある分岐だけが残る。

**適応放散のバースト**は、大量絶滅の直後（ニッチが空く）と、新ケイパビリティ獲得の直後（形質空間が広がる）に自然発生する。特別なコードは不要。

### 2.6 命名

系統名は手続き的に生成する。ケイパビリティ + 主要形質 + 生息環境から語幹を合成:
`Cryo-` (寒冷) `Xero-` (乾燥) `Thermo-` `Halo-` `Photo-` `Macro-` + `-phyta` / `-poda` / `-derm` など。
名前は没入感に効くわりに実装が安いので、必ず入れる。

### 2.7 絶滅

- `B_k` が全セルで閾値を下回ると絶滅。`diedYear` を記録。
- **大量絶滅**は §3.4 の因果連鎖から自然発生する。閾値イベントとしてハードコードしない。
- 系統樹 UI に絶滅が刻まれ、プレイヤーは自分の惑星の歴史を後から読める。**これがプレイの記憶になる。**

## 3. 生物地球化学 — 生命が惑星を殺す機構

### 3.1 酸素は振動する

大酸化事変は**単一イベントではなく過程**である（§06-2.3）:
- 開始 2.46–2.43 Ga、全球氷河作用と同期
- **単調ではなく振動的**、2 億年にわたるオシレーション
- 2.22–2.06 Ga の Lomagundi 事変（オーバーシュートの可能性）
- その終焉は**一次生産の崩壊**を伴った

実装:
```
d(O2)/dt = burial_organic_C · (32/12) − oxidation(還元性ガス, 岩石風化, 呼吸)
```
これを**正のフィードバック付き**にする: O₂ が増える → 大陸の硫化物風化が増える → 硫酸が増える → 硫酸還元菌が増える → …。オーバーシュートとクラッシュが出る系にする。単調増加させない。

**GOE の帰結**: `oxygenToxicity` の高い嫌気性クレードが大量絶滅する。**シアノバクテリアの成功が、それまでの生物圏を壊滅させる。** これが最初のメデア的イベントになる。

### 3.1c 好気呼吸と真核（2026-09-01 実装）★

**真核は 45 億年で一度も出なかった。** `capEukaryotic` の前提は
`oxygenDemand >= 64` だが、適応度が

```ts
oxOk = min(1, o2 / demand)      // 要求 0 が満点
```

だけだったので、**酸素要求はコストだけあって見返りが無く**、選択が
一度も採らなかった（4 seed で採用 0/0/0/0、`capEukaryotic` の提案 0 回）。

直した点:

1. **好気呼吸の見返り**（`aerobicAdvantage`）。好気呼吸はグルコース 1 分子から
   嫌気の約 16 倍の ATP を出す。ただし**酸素があるときだけ**なので、
   優位を `min(1, o2/aerobicHalfO2)` で閉じる。
   ★適応度は 0..1 の掛け算なので、**加点ではなく「酸素のある世界で嫌気を減点」**
   と書く（1 を超えるとクランプで区別が消える）
2. **要求の目盛り**（`oxygenDemandScale`）。現在の大気 21% を基準にしていたので、
   前提を満たすクレードが 4.6% の O2 を要求していた。
   **パスツール点は現代の 1%（0.21%）**（Chapman & Schopf 1983）なので 2% にした

実測（8 seed・全史）: 好気呼吸の定着 0/4 → **5/8**、真核 0/4 → **2/8**。
**GOE → 好気呼吸 → 真核の順序は一度も破れていない**
（gaia-8: GOE 2.65Ga・好気 2.63Ga・真核 0.65Ga。地球は GOE 2.4Ga・真核 1.8〜2.1Ga）。

### 3.1b 実装（2026-08-31）—— **まだ既定 0。入れると惑星が凍る**

**実装: `src/sim/oxygen.ts`。`enabled` は既定 0。**

#### 発端: `globals.o2` を書き換えるコードがどこにも無かった

`grep -rn "globals.o2 =" src/` が空。45.4 億年ずっと 20.9% だった。
CH4 は `ch4FromOxygen(o2)` が決めるので **CH4 も現代の 0.7ppm で固定**され、
無酸素時の上限 `ch4AnoxicMax`（1000ppm）は一度も使われていなかった。

実測（64x32・seed audit・全史。O2 を外から固定して比較）:

| O2 | 太古代 | 顕生代 | CH4 |
|---|---|---|---|
| 20.9%（従来） | **-2.7℃** | 16.8℃ | 0.7ppm |
| 0.001% | **+1.9℃** | 16.7℃ | 50.9ppm |

**太古代だけ 4.6K 暖まり、顕生代は動かない。** 残っている WARN の主因。

#### 収支

```
dO2/dt = 有機炭素の埋没 − マントル由来の還元剤 − 酸化的風化
```

- **埋没**: 一次生産のうち埋まって戻らない分（律速はリン。§3.3）。
  `recalcitrance`（§2.2）が高いほど埋まる
- **還元剤**: マントルが熱いほど多い（太古代は現在の 12 倍）。
  **これが「なぜ GOE があの時期だったか」の答え**になる設計
- **酸化的風化**: O2 が増えるほど速い。**振動（§3.1）を作る負のフィードバック**

#### ★獲得の鎖は通った（2026-08-31 夜）

診断量（`life.diag.proposed` / `adopted`）を足したら、切れている場所が一撃で出た:

#### ★まだ既定 0 —— GOE が起きない惑星が凍るから

**凍る理由はモデルの人為である。** `ch4FromOxygen` は O2 だけで CH4 を決めるので、
**メタンを作る生命がいなくても上限 1000ppm に張り付く**。
CH4/CO2 比が上がってヘイズが点灯し、顕生代が 0.1〜8.0℃ になる。

【次の一手】**CH4 の供給を生命（メタン生成）に結びつける。**
`ch4 = f(O2, メタン生成のフラックス)` にすれば、
生命の乏しい惑星は無酸素でも CH4 が低く、凍らない。
それができてから `oxygen.enabled: 1` にすること。

#### 参考: 入れた当初に凍った理由（解決済み）

冥王代を無酸素で始めると CH4 が上限 1000ppm に張り付き、CH4/CO2 比が上がって
**ヘイズが点灯し、顕生代が 16.8℃ → 1.0℃ に凍る。**
O2 を上げ返すはずの酸素発生型光合成が**一度も獲得されないため。**

獲得の鎖が繋がっていない:

1. 熱水起源の LUCA は**光合成をゼロから作る**必要がある
2. 光合成を得ても、**酸素発生型（ハードステップ）**まで届かない
3. 届いても、そのクレードが**競争で優位に立つ**必要がある

段差は用意した（`chemoFloor` = 熱水から離れた化学合成の効率、
`anoxygenicDonor` = 無酸素型光合成の効率）が、まだ通らない。

★**この過程で分かった設計の要点**: 最初「光合成でなければエネルギー 1.0」に
していたので、**光合成を獲得すると必ず損をして誰も進まなかった。**
化学合成にも制約（熱水への依存）を置いて初めて、光へ進む勾配が生まれる。

★**ハードステップの確率は「基準の 3〜4 桁下」をそのまま使ってはいけない。**
全史で普通の能力が獲得される回数は約 70 回なので、3 桁下げると期待値 0.07 回、
**どの惑星でも一度も起きない**。「45 億年で 1 回」なら 1/70 ≒ 0.014 が正しい。

### 3.2 有機ヘイズと反温室効果

CH₄ が多い N₂ 大気には有機ヘイズが生じ、**太陽光を反射し赤外は透過する = 冷やす**（§01-3.3）。

**帰結**: メタン生成菌を育てすぎると惑星が冷える。**「温室効果ガスを増やしたのに寒くなる」**という非自明な挙動。SimEarth には無かった、教育的価値の高いフィードバック。

### 3.3 リンが長期の律速である

🟢 窒素は生物的に固定できる（`NitrogenFixing`）が、**リンは岩石風化からしか供給されない**。したがって長期的な一次生産の上限はリンが決める。

さらに: **海洋の酸化還元状態がリンの再循環を制御する。** 貧酸素の海はリンを堆積物から放出し（正のフィードバック）、酸化的な海はリンを固定する。これがプロテロゾイックの低酸素状態を長期間維持した機構とされる 🟡。

**帰結**: 「生物量を増やせばいい」ではなくなる。リンの供給（＝造山と風化）が生物圏の天井を決める。**テクトニクスが生命の量を支配する。**

### 3.4 大量絶滅は連鎖である ★

ビッグファイブのうち 4 つは **LIP（巨大火成岩岩石区）** に起因する 🟢。K-Pg のみ天体衝突主因。

**ペルム紀末（2.52 Ga、海生種の 81–94% が絶滅）の殺傷連鎖をそのまま実装する:**

```
① LIP 噴出（LLSVP 縁の上、§01-6.3）
   → CO₂ + SO₂ + ハロゲン放出
② 温暖化（約 +10℃）
   → 海洋の溶存酸素低下 + 成層化（表層が暖まり混合が止まる）
③ 貧酸素 (anoxia)
   → 底生生物の死滅、リンの堆積物からの放出（正のフィードバック）
④ 硫化 (euxinia)
   → 硫酸還元菌 (Cap.SulfateReducing) が優占、H₂S 生成
   → ★生命が生命を殺す
⑤ 海洋酸性化 → 炭酸塩骨格 (Cap.Skeletal) の生物が選択的に死ぬ
⑥ オゾン層破壊（ハロゲン）+ 酸性雨 → 陸上植生の崩壊 → 土壌流出
```

陸上の危機は海洋より **6〜37 万年早く**始まる（応答時間の違い）。この時間差も再現する。

**各段階が寄与台帳に記録される。** プレイヤーは大量絶滅を**読む**ことができる。§03-5.3 の寄与分解パネルの最高の見せ場。

### 3.6 空中生物圏 🟡 ★金星化した惑星の逃げ場

**起源としての空中は否定される**（§2.8）が、**派生した生息場所としては実在する** 🟢。

- 大気には本物の微生物生態系がある。単なる浮遊塵ではなく、**雲の中で代謝し分裂している**
  証拠がある（Womack et al. 2010）
- **金星の雲層に永続的な空中生物圏**を置く真面目な提案がある（Seager et al. 2021）。
  地表が 460℃ でも高度 50km 付近は約 30℃・1 気圧である

**ゲーム機構としての価値**: 本作の敗北条件のひとつは「金星化」だが、
地表が死んでも**雲層だけで生き残る生物圏**という分岐を用意できる。

```
地表温度 > 100℃ かつ 雲層に液相の水が存在
  → Cap.Aerial を持つクレードのみ生存
  → 地表の生物圏は全滅、空中生物圏だけが残る
```

海のプランクトンとの類推は正確である（浮遊して一次生産する、沈降が死を意味する）。
沈降速度と上昇気流のつり合いが生存条件になるので、
**大気循環の強さが直接に生存を決める**という、他にない結合が作れる。

### 3.5 後期デボン紀 — 陸上植物が海を殺す

🟢 維管束植物（`Cap.Vascular`）の登場は両義的:

| 効果 | 符号 |
|---|---|
| 根系による風化促進（`weatheringBoost`） → CO₂ 低下 | ガイア的 |
| 土壌形成 → 陸上生態系の基盤 | ガイア的 |
| **栄養塩（P, N）の海への流出 → 富栄養化 → 貧酸素 → 海洋大量絶滅** | **メデア的** |
| リグニン（`Cap.Lignin`）による炭素隔離 → O₂ 上昇、CO₂ 低下、寒冷化 | 両義的 |

**同じ形質から両方が出る。** プレイヤーが「陸を緑にしよう」と育てた植物が海を殺す。これが柱 3（§00-4）の最も分かりやすい実例になる。

## 4. 文明 ★全面改訂

> 前バージョンの「狩猟採集 → 農耕 → 産業 → 情報 → 惑星 → 恒星間」という技術時代の階段は、
> **現代考古学がほぼ全面的に否定している枠組み**である（§06-6）。廃棄する。

### 4.1 発生

「知性グレードに到達した」ではなく、**ケイパビリティの組み合わせ**で判定する:

```
Cap.Social | Cap.Symbolic | Cap.Motile  +  brain 形質  +  道具使用に足る体制
```

そして重要な点: **知性は多数ある形質到達点の一つに過ぎない。到達しない惑星が普通にある。** 知性への一本道は存在しない。

発生は単一地点ではない。**複数の集団がメタ個体群として並立し、分岐と再融合を繰り返す**（braided stream, §06-6.1）。実装上は複数の `Society` を持ち、交流・混合・分離を行う。

### 4.2 社会の状態 — 階段ではなく多次元

```ts
interface Society {
  id: number
  cells: Set<number>            // 占有セル
  population: number

  /** 生業ミックス（合計 1.0）。階段ではなく連続的な配合 */
  subsistence: {
    foraging: number            // 採集狩猟
    horticulture: number        // 園耕
    agriculture: number         // 集約農耕
    pastoralism: number         // 牧畜
    fishing: number
  }

  /** 主軸指標: 一人あたりエネルギー捕捉量 (kcal/person/day 相当) */
  energyCapture: number

  /** 社会規模と階層性。★どちらも可逆 */
  scale: number                 // 最大の集住単位の人口
  hierarchy: number             // 0..1。階層の深さ

  /** 知識の蓄積。崩壊しても部分的に残る */
  knowledge: number

  /** 惑星恒常性への自己認識 (Gaia 2.0) */
  gaiaAwareness: number
}
```

**技術ツリーを持たない。** 代わりに `energyCapture` を主軸にする。これは Ian Morris の社会発展指数などで使われる比較的合意の得やすい定量指標であり、しかも**惑星への影響と直接結びつく**（CO₂ 排出、土地改変）。技術ツリーより遥かに素直にシミュレーションに載る。

### 4.3 生業は選択であり、可逆である

🟢 農耕は世界で **11 箇所以上で独立に発生**し、**数千年かけて漸進的に**成立し、**何度も放棄された**。農耕移行後に健康状態は悪化した（身長低下、齲蝕、感染症）。「農耕＝進歩」は成立しない。

```
d(agriculture)/dt = f(
   気候の安定性,           // 不安定だと農耕は割に合わない
   野生資源の可用性,        // 豊かなら農耕しない
   人口圧,
   土壌肥沃度,
   近隣社会からの伝播
) − 放棄圧
```

**放棄が起こりうること**が本作の文明モデルの肝。気候が悪化すれば農耕を捨てて採集に戻る。それは後退ではなく適応である。

### 4.4 階層性も可逆である 🟡

Graeber & Wengrow (2021) の中核主張 —「バンド → 部族 → 首長制 → 国家」という一方向の階段は証拠に反する。記念碑建築は農耕に先行する（ギョベクリ・テペ 紀元前 9500 年頃）。社会は季節ごとに異なる政治形態を行き来した。

> **注意 🟡**: 本書は専門家からの批判も強い（証拠の選択的使用、二分法的推論）。
> **「一本道の階段は間違い」という中核主張は広く受容されているが、代替の枠組みは確立していない。**
> したがって本作は「可逆な多次元状態」という**最小限のコミットメント**に留め、特定の理論を機構化しない。

実装: `hierarchy` と `scale` は上下する連続量。集約する圧（人口密度、防衛、灌漑）と分散する圧（移動性、資源分散、不満）の釣り合いで決まる。

### 4.5 崩壊は再編である 🟢

🟢 ラパ・ヌイの「エコサイド」神話は考古学的に否定された。森林減少は起きたが、ヨーロッパ人接触**以前**の人口崩壊の証拠は乏しい。人口崩壊は接触後の**疫病と奴隷貿易**による。マヤの「崩壊」も消滅ではなく再編と移動。

```
崩壊 (collapse) := scale ↓↓, hierarchy ↓↓, energyCapture ↓
                   population は減るが 0 にはならない
                   knowledge は部分的に残る（断絶の度合いは規模に依存）
                   生業は集約農耕から採集・園耕へシフト
```

**「文明が滅んだ」演出をしない。** 「大きな中心が失われ、人々は分散した」と表示する。数千年後、別の配置で再び集約が起こる。

### 4.6 惑星への作用

```
CO2_emission   = population × energyCapture × carbonIntensity(エネルギー源の構成)
landConversion = population × landPerCapita(subsistence ミックス)
nutrientFlux   = agriculture 比率 × 施肥強度   // ★富栄養化 = §3.5 と同じ機構
pollution      = f(energyCapture, 人口, 技術)
extinctionPressure = f(landConversion, 狩猟, 汚染, 移入種)
```

**化石燃料は有限リザーバ**であり、その量は §3.1 で埋没した有機炭素の総量に等しい。**過去の生命が文明の燃料である。** 生物圏が貧しかった惑星では産業化が起こらない。この結合は実装が安く、効果が大きい。

**排出速度の非対称性**が終盤の中心的緊張になる:
```
文明の CO₂ 排出:   〜10 Gt-C/yr
火山の脱ガス:      〜0.1 Gt-C/yr
風化の応答時間:    10⁵ 〜 10⁶ 年
```
**ガイアの負のフィードバックは、文明の速度に対して 4 桁遅い。** しかも供給律速なら効きすらしない（§01-4.2）。

### 4.7 ティッピング要素

文明期には気候を連続変数だけで扱わない。閾値を越えると**不可逆に状態遷移する要素**を明示的に持つ（§01-3.6）:
AMOC 崩壊、氷床崩壊、熱帯林の草原化、永久凍土の炭素放出、サンゴ礁。

UI には「あとどれだけで戻れなくなるか」の距離メーターを置く。数値ではなく**残された余地**を見せる。

### 4.8 自己認識 — Gaia 2.0

🟢 Lenton & Latour (2018), *Science*。人類は「自己認識を持ったガイア」であり、初めて意図的な惑星制御が可能になった段階。

`gaiaAwareness` が上がる要因:
- 環境危機を経験して**生き延びた**（人口は減るが再編できた）
- `knowledge` の蓄積
- 惑星規模の観測能力の獲得
- プレイヤーの介入「啓示 (Revelation)」（高コスト）

下がる要因:
- 危機がない（＝学習しない）
- 崩壊による知識の断絶

高いと社会は自発的に排出を抑え、生態系を修復し、**やがてプレイヤーの役割を引き継ぐ**。これが勝利条件の最終段階（§03-3.2）。

### 4.9 人新世は「世」ではない 🟢

2024 年 3 月、IUGS は人新世を正式な地質学的な「世」とする提案を**否決**した。2026 年現在も覆っていない。代わりに「**イベント**」として扱う流れがある。

**帰結**: 人新世をゲーム内の「到達する時代」にしない。**惑星側の指標**として測る — 「この時代の地層には、放射性核種・プラスチック・窒素同位体異常・花粉の急変が記録されている」。プレイヤーは自分の惑星の地層を読む。

### 4.10 シルル紀仮説 — 周回をまたぐ仕掛け 🟡

Schmidt & Frank (2018): *もし地球に数千万年前に産業文明があったとして、我々はそれを地質記録から検出できるだろうか？*

**帰結**: 前の周回（§03-7 のメタ進行）で滅びた文明が、**地層に痕跡を残す**。次の周回の知的種が、堆積物中の異常な同位体比や合成物質を発見する。柱 1（逐次選択）と完全に噛み合う。
