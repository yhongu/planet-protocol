# 01. シミュレーションモデル

> 科学的な根拠と 1990 年からの改訂点は [06-science-basis.md](06-science-basis.md) を参照。
> 各項目の 🟢 定説 / 🟡 有力だが係争中 / 🔴 係争中 の表記も同文書に準じる。

## 0. 設計方針

1. **物理的に「正しい」より、因果が「読める」ことを優先する。** ただし読めた因果は現代の地球科学と同じ向きを持つこと。誇張はしてよいが、嘘の符号はつけない。
2. **すべての式は寄与に分解可能な形で書く。** `T += f(...)` ではなく `contributions[] を積んでから合計する`。UI の寄与分解パネル（§03-5.3）がこれに依存する。
3. **決定論的であること。** 乱数はすべて seed 付き PRNG 経由。
4. **数値的に爆発しないこと。** 陽解法で回す以上、各サブシステムに安定条件とクランプを設ける。
5. **🔴 の論点はパラメータとして露出させる。** 決着していない科学を断定しない。サンドボックスのスライダーにするのが最も誠実で、かつ最も面白い。

### 実装の直接の参考になる既存モデル ★

本作のシミュレーション層は、以下の**実際に動く地球システムモデル**の構造を借用する。ゼロから式を考案しない。

- **COPSE reloaded** (Lenton et al. 2018) — 顕生代の C・O・P・S と生物進化の結合ボックスモデル
- **SCION** (Mills et al. 2021) — COPSE に 3D 気候エミュレータと 2D 大陸風化スキームを追加した空間解像版。**GitHub 公開**。本作の構成（空間グリッド + 生物地球化学ボックス）と極めて近い
- **GEOCLIM** — 空間分解した風化-気候結合

M2（炭素循環）の実装前に SCION のソースを読むこと。数百時間の節約になる。

## 1. 時間スケール階層

SimEarth 最大の構造的欠陥は、地質（10⁶ 年）と文明（10⁰ 年）を同一ティックで回したことにある。本作はサブシステムごとに**更新間隔**を持つ。

```ts
interface Subsystem {
  name: string
  /** このサブシステムが1回更新されるのに必要なシミュレーション年数 */
  stepYears: number
  update(planet: Planet, dtYears: number): void
}
```

| サブシステム | stepYears | 備考 |
|---|---|---|
| Mantle（マントル熱史・テクトニクス様式） | 10,000,000 | 惑星の熱時計（§6.1） |
| Tectonics（プレート） | 500,000 | 大陸移動は 1cm/年 オーダー |
| Weathering / 炭素長期循環 | 100,000 | 風化の応答時間 |
| Climate（EBM） | 100 | 平衡に近いので粗くてよい |
| Hydrology（水循環） | 100 | Climate と同期 |
| Ecology（個体数動態） | 1,000 | |
| Evolution（クレード分岐） | 10,000 | |
| Civilization | 1 | 社会が存在するときのみ |

### エポックと速度 ★実装で確定した値

**速度の上限は物理が決める。** 風化フィードバックの応答時定数は約 210 kyr（実測）。
これを分解するには 1 ステップ 20〜40 kyr 以下でなければならず、60fps なら:

```
上限 = 40,000 年/ステップ × 60 ステップ/秒 = 2.4 M 年/秒  ->  2,000,000 年/秒 を採用
```

これを超えると、温度が上がっても風化が追随せず**サーモスタットが嘘になる**。

**下限は 1 年/秒。** 本作は季節を持たない（年平均モデル）ので、
1 年より細かい時間刻みには物理的な意味がない。

★**2026-08-31 に「時代ごとの標準速度 × 倍率」をやめ、絶対値の段にした。**

【なぜ変えたか】以前は時代ごとに標準速度が 500,000〜1 年/秒と 5 桁変わり、
**同じ ×1 でも時代で速さが変わった**。プレイヤーからは「なぜ急に速く（遅く）
なったのか」が分からない。さらに表示が実測のレート（進んだ年数 ÷ 実時間）
だったので **100.5 kyr/秒 や 145 kyr/秒 のように揺れ、FPS のように見えた**。

いまは:

| 段 | 速度 | 全史 4.54 Gyr の所要 |
|---|---|---|
| ×1 | 100,000 年/秒 | 12.6 時間 |
| ×5 | 500,000 年/秒 | 2.5 時間 |
| ×10 | 1,000,000 年/秒 | 1.26 時間 |
| ×20 | 2,000,000 年/秒（**物理上限**） | 38 分 |

- **どの時代でも同じ年数/秒。** 速く見たい時代はプレイヤーが段を上げる
- **表示は設定値**。追いつけないときだけ「⚠追いつけず」を出す（`throttled`）
- 時代は**天井をかぶせるだけ**（`EpochDef.maxYearsPerSecond`）。
  人新世は 500 年しかないので 20 年/秒で頭打ちにする

ティックの階段（`TICK_LADDER`）にも 5,000 / 100,000 / 250,000 を足して、
どの段も「毎秒およそ 20 ティック」に落ちるようにした。
5 万年より大きい刻みでも `world.chunked` が気候の結合間隔（5 万年）で
刻み直すので**物理は変わらない**。

**×1 で通すと約 3.9 時間、×4 で約 57 分。** 停止して考える時間を含めて 2〜3 時間という
設計目標（§00-6）に合う。×4 が物理上限にちょうど当たるようにしてある。

\* 正式な地質年代ではない（§06-6.5、IUGS 2024 否決）。時間解像度モードの名称として使う。

**サブステップと速度の抑制:**

各サブシステムは `preferredStepYears`（精度上望ましい刻み）と
`maxStepYears`（許容できる最大の刻み）を持つ。1 フレームの進行年数が
`preferredStepYears` を超えるときはサブステップに刻む（上限 16 回/フレーム）。

**それでも `maxStepYears` を超える場合は、進行年数そのものを減らす。**
黙って精度を落とすより、シムが遅くなる方が誠実（§0 方針 1）。
UI には「上限に当たっている」ことを表示する。

| サブシステム | preferred | max | 根拠 |
|---|---|---|---|
| Carbon（炭素循環） | 25,000 年 | 50,000 年 | 風化の応答時定数 210 kyr の 1/8 |
| Tectonics（M4） | 500,000 年 | 1,500,000 年 | プレートが 1 セル進むのに 1.5 Myr |
| Ecology（M5） | 1,000 年 | 20,000 年 | 個体数動態の緩和時間 |
| Civilization（M6） | 1 年 | 5 年 | 人口動態 |

## 2. 惑星データモデル

### 2.1 グリッド

- `W × H` の等緯度経度グリッド。既定 256 × 128。
- x 方向は**巡回**（`(x + W) % W`）。
- y 方向は極で閉じる（熱フラックス 0 の境界）。
- セル `(x, y)` の緯度: `φ = (0.5 - (y + 0.5) / H) * π`（y=0 が北極側）。
- セル面積: `area(y) = R² · (2π/W) · (sin φ_top − sin φ_bottom)` — **面積の緯度依存を必ず入れる**。忘れると全球平均がすべて狂う。

### 2.2 セルフィールド（Structure of Arrays / Float32Array）

```ts
interface PlanetFields {
  // --- 地質 ---
  elevation:    Float32Array  // m。海面基準
  crustType:    Uint8Array    // 0=oceanic, 1=continental
  crustAge:     Float32Array  // Myr
  plateId:      Uint8Array
  volcanism:    Float32Array  // 0..1
  erosionRate:  Float32Array  // ★風化の供給律速に必須（§4.2）
  regolith:     Float32Array  // 風化可能な新鮮岩石の在庫（m）★

  // --- 水・氷 ---
  iceThickness: Float32Array
  soilMoisture: Float32Array

  // --- 気候 ---

  albedo:       Float32Array  // 毎ティック導出

  // --- 海洋（2層） ---
  sstAnomaly:   Float32Array
  o2Ocean:      Float32Array  // 溶存酸素 ★貧酸素・硫化の判定に必須
  phosphorus:   Float32Array  // ★長期の律速栄養（§02-3.3）
```


### 2.4 太陽の進化と「暗い太陽のパラドクス」

```
S(t) = S_now / (1 + 0.4 * (1 - t / 4.57Ga))
```
40 億年前の太陽は現在の約 70%。それでも地球は凍らなかった。

**1990 年の標準解（メタン温室）は現在は採らない** 🟢。CH₄ が多いと N₂-CH₄ 大気に**有機ヘイズ**が生じ、これが**反温室効果**（太陽光を反射し赤外は透過）で惑星を冷やす。メタン温室には自己制限がある。

現在の理解は**複合要因**:

| 要因 | 寄与 | 確度 | 実装 |
|---|---|---|---|
| 高濃度 CO₂ | 大きいが古土壌の制約で上限あり | 🟢 | §3.3 |
| **陸地面積が小さい → アルベド低下** | 数 K | 🟢 | 太古代は大陸成長が未完（§6.1） |
| **生物起源の雲凝結核 (CCN) の不在 → 雲が少なく粗い** | 3–7 K | 🟡 | `ccn` フィールド（§3.2） |
| **N₂ 分圧による圧力広がり** | N₂ 倍で 4–5 K | 🔴 | `n2Pressure` スライダー |
| CH₄ 温室 | 限定的（ヘイズが自己制限） | 🟢 | §3.3 |

### 2.4b ★実装 — 太陽の時間発展と冥王代の初期状態

**しばらくの間、`solarConstantAt()` は書かれていたが呼ばれていなかった。**
太陽は 45.4 億年ずっと 1361 W/m² のままで、しかもゲームの初期状態は
「現在の地球」（CO₂ 280ppm・平均 14.5℃・氷率 0.115）に「冥王代」というラベルが
付いているだけだった。冥王代に現在と同じだけ氷があることに気づいて発覚した。

#### 直した内容

| | 修正前 | 修正後 |
|---|---|---|
| 太陽定数 | 45.4 億年ずっと 1361 W/m² | 974 → 1361 W/m²（72% → 100%） |
| 初期 CO₂ | 280 ppm | 100,000 ppm（0.1 bar） |
| 初期 CH₄ | 0.7 ppm | 100 ppm（非生物起源） |
| 初期マントル | 1350℃（現在） | 2250℃（マグマオーシャン） |
| 初期の平均気温 | 14.5℃（＝現在） | 1.6℃ |
| 初期の氷率 | 0.115（＝現在） | 0.275（**極域のみ**） |

`solarConstantAt` の引数は【太陽の年齢】であって「何年前か」ではない。
経過年数からは `solarConstantForElapsed()` を通すこと（`src/sim/state.ts`）。

#### 冥王代の初期値の根拠

- **CO₂ 0.1 bar**: 冥王代の推定範囲 0.1〜10 bar (Zahnle et al. 2007) の下限。
- **CH₄ 100 ppm**: 蛇紋岩化による**非生物起源**のメタン (Kasting 2005)。
  冥王代にメタン菌はいないので、生物起源を仮定してはいけない。
- **平均 1.6℃・氷率 0.275**: 液体の水があり極に氷がある「冷たい初期地球」
  (Valley et al. 2002 "A cool early Earth")。全球凍結ではない。
  冥王代の氷河堆積物の証拠は無いが**冥王代の岩石記録自体がほぼ無い**ので強い反証にならない。
  最古の氷河堆積物はポンゴラ氷期（約 29 億年前）。

#### ★測って確かめた: モデルは暗い太陽のパラドクスを正しく再現する

冥王代の太陽（974 W/m²）の下で CO₂ を振ると:

| CO₂ [ppm] | 平均T | 氷率 | |
|---|---|---|---|
| 280 | **−37.5℃** | 1.000 | 現在の CO₂ では**完全凍結**。これがパラドクスそのもの |
| 30,000 | −27.1℃ | 0.992 | まだ雪玉 |
| 60,000 | −11.9℃ | 0.547 | ここで分岐する |
| 100,000 | −8.4℃ | 0.460 | |
| 100,000 + CH₄ 100 | **+1.6℃** | 0.275 | 採用した初期状態 |

**雪玉のヒステリシスも出る**（凍った状態から CO₂ を上げ直した場合）:

| | 閾値 |
|---|---|
| 温暖 → 凍結 | 3〜6 万 ppm |
| 凍結 → 脱出 | **約 20 万 ppm（0.2 bar）** |

約 3 倍のヒステリシス幅。Snowball Earth 理論の予測（脱出に 0.1 bar 級の CO₂ が要る、
Hoffman et al. 1998）と整合する。**これは仕込んだものではなく、氷アルベド帰還から出てきた。**

#### 太陽のつまみは「倍率」

`globals.solarMultiplier` は主系列進化に**掛ける**値。1.0 なら実際の太陽の歴史をなぞる。
`globals.solarConstant` は実効値で、物理はこれだけを見る。

**UI の初期化で踏んだ罠**: 起動時にスライダーの初期値を Worker に送っていたため、
せっかく作った冥王代の状態（CO₂ 10%・暗い太陽）を
スライダーの既定値（CO₂ 280ppm・太陽 1.0 倍）が**上書きしていた**。
スライダーは世界の実態に合わせる側であって、指示する側ではない。

### 2.5 🔴 の露出方針

pN₂ は真っ向から対立している（Goldblatt らは現在の 2〜3 倍、Som らは雨痕と玄武岩の気泡から現在以下と主張）。**決着していない。**

これはサンドボックスのスライダーにする。**「科学が分かっていないことを、プレイヤーが試せる」**のは減点ではなく本作の魅力にする。同様の扱いをするもの: プレートテクトニクス開始時期、LHB の有無、初期海洋量。

## 3. 気候モデル — 2次元エネルギーバランスモデル (EBM)

GCM は不可能。**Budyko–Sellers 型の EBM** を採用する。氷アルベドフィードバックとスノーボール分岐を正しく生む最小のモデルで、Daisyworld をそのまま内包できる。

### 3.1 支配方程式

セル `i` について:

```
C_i · dT_i/dt  =  S_i (1 − α_i)  −  (A + B·T_i)  +  D·∇²T  +  F_i
```

| 項 | 意味 | 実装 |
|---|---|---|
| `C_i` | 実効熱容量 | 海 = 高、陸 = 低、氷 = 中 |
| `S_i` | 入射日射 | `S0/4 · s(φ)`、`s(φ) = 1 + s₂·P₂(sin φ)`、`s₂ = −0.477` |
| `α_i` | アルベド | §3.2 |
| `A + B·T` | 射出長波放射の線形化 | **`B = 2.2206 W/m²/K`**（較正値）。プランク応答ではなく**水蒸気・気温減率・雲を込みにした実効値**。`A` に温室効果を埋め込む（§3.3） |
| `D·∇²T` | 大気＋海洋の南北熱輸送 | **温度依存の湿潤拡散**（下記）。定数 `D` では緯度分布が合わない |
| `F_i` | 外部強制 | 火山エアロゾル、隕石ダスト、プレイヤー介入 |

### 3.2 アルベドの合成

```
α = clamp(α_surface + α_cloud(cloudCover, ccn) + α_haze(hazeOpticalDepth), 0.05, 0.90)
```

| 表面 | α |
|---|---|
| 海洋（開水面） | 0.08 |
| 海氷 / 氷床 | 0.62 |
| 裸地・岩石 | 0.30 |
| 砂漠 | 0.38 |
| 草原 | 0.20 |
| 森林 | 0.12 |

**生命との結合が 2 本ある:**

1. **Daisyworld ルート** — 植生クレードの `albedoEffect` 形質が `α_surface` を直接変える。明るい植生は冷やし、暗い植生は暖める。
2. **CCN ルート** ★ — クレードの `ccnProduction` 形質が `ccn` フィールドを増やす。CCN が多いと雲粒が小さく多くなり、**雲アルベドが上がる**。

> CLAW 仮説（プランクトン → DMS → 雲 → アルベド → 気候の負のフィードバック）は
> 実測で支持されなかった 🟢 (Quinn & Bates 2011)。
> **しかし CCN の生物起源そのものは実在する。** 本作は結合の強さを誇張して機構化するが、
> 「これは CLAW ではなく、CLAW が想定したより弱い実在の効果を誇張したもの」と
> ゲーム内の解説で明示する。**否定された仮説を事実として提示しない。**

### 3.3 温室効果と反温室効果

`A` を大気組成の関数にする（放射強制の標準的な対数近似）:

```
A = A0 − 5.35·ln(CO2/280)·pressureBroadening(n2Pressure)
       − 0.036·(√CH4 − √700)
       − f_H2O(T)
       + f_haze(CH4/CO2)      // ★符号が逆 = 冷やす
       + f_aerosol(火山, 文明)
```

- **`A0 = 209.134 W/m²`**（`proto/calibrate.py` の較正値。T は ℃）
- **水蒸気フィードバック** `f_H2O(T)`: 正のフィードバック。Clausius–Clapeyron に従い `∝ exp(T/13.7)`。暴走温室（金星化）の分岐を生む。**必ず上限クランプを置く**。
- **圧力広がり** 🔴: `n2Pressure` が高いと CO₂・CH₄ の吸収帯が広がり温室効果が増す。係争中なのでスライダー。
- **有機ヘイズ** ★ 🟢: `CH4/CO2` 比が閾値（およそ 0.1）を超えると光化学的にヘイズが生成され、**太陽光を反射し赤外は透過する**。

> **実装場所の訂正**: ヘイズは `A`（OLR）の項ではなく**アルベド側に入れる**。
> 「太陽光を反射する」という物理そのままであり、プロトタイプもそう実装した。
> シグモイドは比ゼロで厳密にゼロになるよう正規化すること（素のシグモイドは裾が太く、
> CH₄ が微量でもアルベドが 0.017 残る。`proto/RESULTS.md` §5）。

```
ratio = CH4 / CO2
α_haze = α_haze_max · normalized_sigmoid(ratio; 閾値 0.10, 幅 0.04)
較正値: α_haze_max = 0.22
```

**帰結**: メタンを増やしすぎると惑星が冷える。「温室効果ガスを増やしたのに寒くなる」という非自明な挙動。

**プロトタイプで検証済み** — 太古代設定（S = 0.78 S₀、CO₂ = 20,000 ppm）で CH₄ を掃引すると、
**CH₄ ≈ 400 ppm で昇温がピーク（5.3℃）を打ち、そこから 49℃ 低下してスノーボールに落ちる。**

#### 湿潤熱輸送 ★ プロトタイプで判明した必須要素

定数拡散の EBM は**赤道と極を同時に合わせられない**（既知の限界）。実際の南北熱輸送の大部分は
潜熱（水蒸気）が担っており、Clausius–Clapeyron により暖かいほど強い。そこでセル境界温度に
依存する実効拡散係数を使う:

```
D_eff = D · (1 + k_moist · max(0, exp((T_edge − T₀)/Tq) − 1))
較正値: D = 0.28 W/m²/K,  k_moist = 2.0,  Tq = 20 K
```

これを入れないと、赤道 31℃ / 極 −19℃ のように**熱帯が熱すぎ極が暖かすぎる**分布になる。
`proto/RESULTS.md` §5 の罠 #3。

### 3.5 数値解法 ★実装で 4 回失敗した箇所

**平衡化ショートカット**の方針は正しい（地質エポックでは気候は常に平衡にある）。
問題は「どう解くか」で、素朴な方法はことごとく破綻した。記録しておく。

| 試したこと | 結果 |
|---|---|
| 赤黒 Gauss-Seidel | **収束しない**。系が拡散支配（D·c が B の 100 倍）で、拡散の一部でも陽的に扱うと収束率が 1 − B/(D·c) ≈ 0.99 になる |
| 南北方向の線形陰解法 + 東西を右辺 | やはり収束しない。同じ理由（極では東西結合が南北の 2 万倍で、極の行が凍りつく） |
| 面積で対称化 → Jacobi 前処理 CG | 収束するが CG が 300 反復に張り付く。対称化すると B の項にセル面積が掛かり、B·w が Σg の 0.1% しかない = ほぼ純粋なラプラシアン（定数モードの固有値がほぼゼロ、条件数 6000） |
| 南北ライン前処理 CG | CG は数十反復に改善。しかし外側の Picard が収束しない（氷アルベドのループゲイン 0.77） |
| dα/dT を対角に入れて Newton 化 | 氷縁でセルの 12% が局所不安定（S·dα/dT ≈ −7.5 が B = 2.22 を上回る）。ヤコビアンがほぼ特異になり、1 歩目で残差が 0.19K → 12.3K に発散 |
| Newton + バックトラック線形探索 | 振動して停滞。**残差ノルムが単調な指標にならない** — 氷縁は局所不安定なので、平衡に向かう正しい一歩でもその近傍の残差は増える |
| **擬似時間発展法 (pseudo-transient continuation)** | ✅ **これが正解** |

**採用した解法:**

```
ヤコビアンに擬似的な熱容量項を足す:
    (w·(B_eff + c/dt) + L) ΔT = F_steady
  - 物理的には「陰的オイラーで気候を dt 年進める」ことに等しい
  - dt が有限なら常に正定値・安定
  - 残差が下がるにつれて dt を伸ばす (SER 則)。dt → ∞ で Newton に一致
  - 線形探索ではなく【適応的な時間刻み】: 残差が 3 倍以上悪化したときだけ
    差し戻して dt を縮める
```

副次的な利点として、これは**物理的な緩和過程そのもの**なので、複数平衡があるときに
**物理的に到達する側**の平衡に落ちる。スノーボールのヒステリシス（§3.7）が正しく再現される。

**その他の実装上の注意:**

- **収束判定は Newton の歩幅 [K] で行う。** 残差ノルムを `w·B` で正規化すると極セル
  （面積が極小）で発散し、`w·B + Σg` で正規化すると `Σg` が 3000 倍あるため
  平衡から 0.77K ずれていても 3e-4 としか出ない。どちらも判定に使えない。
- **クランプ（`T ∈ [−120, +500]`）に張り付くと歩幅がゼロになり「収束」と誤判定される。**
  クランプが効いている限り収束とみなさないこと。暴走温室・全球凍結の検出にもなる。
- 極フィルタ（東西結合係数の上限）は入れてよい。極の行は物理的に東西一様なので、
  上限を 8 倍に置いても解は変わらない（検証済み）。条件数だけが下がる。
- 粗格子で解いてから内挿する (nested iteration) と冷間開始が 3〜5 倍速くなる。

### 3.6 ティッピング要素 ★1990年には存在しなかった枠組み

Lenton et al. 2008 以降。気候を連続変数だけで扱わず、**閾値を越えると不可逆に状態遷移する要素**を明示的に持つ。

```ts
  id: 'amoc' | 'iceSheetN' | 'iceSheetS' | 'rainforest' | 'permafrost' | 'coral' | 'monsoon'
  state: number          // 0..1
  threshold: number      // 越えると遷移開始
  transitionYears: number
  hysteresis: number     // 戻すのに必要な超過量（大きい = 実質不可逆）
```

### 4.2 ケイ酸塩風化 ★最も重要な改訂

**前バージョンで最も単純化しすぎていた箇所。**

1990 年の理解（Walker–Hays–Kasting）: 温度が上がれば風化が速まり CO₂ が下がる。**無条件の負のフィードバック。**

現在 🟢: 温度依存の風化がサーモスタットとして機能すること自体は支持されている (Brantley et al. 2023, *Science*)。**しかし 2 つのレジームがある:**

```
weathering = min( kineticLimit, supplyLimit )

kineticLimit = W0 · (CO2/CO2_0)^0.3
                  · exp((T − T0)/13.7)      // ★温度依存 = 負のフィードバックの核
                  · f_runoff(runoff)
                  · f_biota(weatheringBoost) // 陸上植物が 2〜5 倍に加速

supplyLimit  = k · erosionRate               // ★新鮮な岩石の露出速度が律速
             = k · f(傾斜, 造山活動, 氷河侵食, 降水)
```

| レジーム | 状態 | 挙動 |
|---|---|---|
| **速度論律速** | 新鮮な岩石が十分にある | **古典的な負のフィードバックが効く。惑星は温度を自己調節する** |
| **供給律速** | 侵食が追いつかない | **温度を上げても風化は増えない。サーモスタットが壊れる** |

🟡 Maher & Chamberlain (2014): **地球全体は両レジームの遷移帯にある。** 河川ごとにばらつく。
🟡 熱力学的制約下では、風化速度が温度上昇で**減少しうる**（正のフィードバックに反転する）という指摘もある。

**ゲームへの帰結 — これがゲームを面白くする:**

> **惑星のサーモスタットは、山があるときだけ効く。**

- 超大陸が平坦化して侵食が止まると供給律速になり、**サーモスタットが壊れて温暖化が暴走する**。
- 造山運動が活発になるとサーモスタットが復活して寒冷化する（新生代のヒマラヤ隆起 → 氷河時代、Raymo & Ruddiman 仮説 🟡）。
- **テクトニクスが気候の安定性そのものを支配する。** §7 の結合図に太い矢印が 1 本増える。

実装上は `regolith`（風化可能な新鮮岩石の在庫）フィールドを持ち、侵食が供給し風化が消費する。在庫が尽きたセルは供給律速に落ちる。**在庫の可視化レイヤを用意すること** — プレイヤーが「サーモスタットの残り」を見られる。

#### 判明したこと ★

**(1) 「崖」は 1 次元のアーティファクトだった。訂正する。**

1 次元プロトタイプでは、侵食を 2.0 → 0.15 と落としていくと **侵食 ≈ 0.67 までは何も起きず、
そこを跨いだ瞬間に平衡 CO₂ が急上昇する**という劇的な結果が出た。
当初これを「崖がある」と記述したが、**2 次元で再現しなかった**。

原因: 1 次元は惑星全体を 1 セルとして扱うので、`min(速度論, 供給)` の切り替えが
**惑星全体で同時に**起こる。2 次元では侵食が空間的にばらつくため、
セルごとに違う侵食量でレジームが切り替わり、集計すると滑らかになる。

**2 次元の応答（M3 の水循環駆動の侵食を使った値）:**

| 侵食倍率 | 平衡 CO₂ | 全球平均気温 | 供給律速の面積 |
|---|---|---|---|
| 2.00 | 228 ppm | 13.5℃ | 1% |
| 1.00 | **280 ppm** | **14.5℃** | **25%** |
| 0.70 | 339 ppm | 15.3℃ | 34% |
| 0.50 | 404 ppm | 16.1℃ | 40% |
| 0.25 | 535 ppm | 17.3℃ | 46% |
| 0.15 | 624 ppm | 17.9℃ | 49% |

不連続はどこにもない。それどころか **応答は飽和する**。

> **M2 の段階（傾斜だけの暫定侵食）では侵食 0.2 で 1375 ppm まで上がったが、
> M3 で水循環駆動の侵食に置き換えたら 624 ppm で頭打ちになった。**

理由は侵食の**空間分布の広がり**。水循環を入れると侵食速度は
陸地内で **587 倍**（p1 と p99 の比）に広がる —— 造山帯・大河の流域と、
乾いた平坦な楯状地では、桁が 2 つ以上違う。

一律に侵食を落としても、**高侵食の「エンジン」領域は供給を保ち続ける**。
そこが全球の風化フラックスをほぼ独占するので、全体の応答が飽和する。

**これは現実の姿と一致する。** 全球のケイ酸塩風化フラックスの不釣り合いに大きな割合が、
活動的な造山帯（ヒマラヤ、アンデス、台湾、ニューギニア）で起きている。

**ゲーム設計への含意**: **プレイヤーの惑星のサーモスタットは、少数の造山帯が担っている。**
大陸全体を均すのではなく、**どこに山があるか**が効く。
M4 のプレートテクトニクスで衝突帯を作ることが、そのまま気候の安定性への投資になる。

**2 次元の方が正しい。** 実際の地球でも侵食は桁で変動し（ヒマラヤ vs アマゾンの楯状地）、
Maher & Chamberlain 2014 は「河川ごとにばらつき、全球平均が遷移帯にある」と述べている。
**全球の風化フラックスに鋭い崖はない。滑らかなクロスオーバーがある。**

**(2) ゲーム設計としてはむしろ改善である。**

崖なら「何も起きない → 突然の破局」で、プレイヤーに読む余地がない。
滑らかな加速なら、**供給律速の面積割合が先行指標になる**:

> 侵食 1.0 で 25% → 侵食 0.3 で 69%。
> **CO₂ が本格的に動き出す前に、地図の上で見える。**

これが `docs/03-5.2` の「新鮮岩石の在庫レイヤ」の存在理由になる。
プレイヤーは大陸が灰色に染まっていくのを見て、サーモスタットが弱っていくことを読む。
「崖に落ちてから気づく」より、はるかに良いゲーム体験になる。

**(3) 較正は 2 拘束を同時に満たすこと。**

`min(速度論, 供給)` を使う以上、**速度論側だけを W0 に合わせると必ず定常が崩れる**
（供給律速に落ちたセルの分だけ総量が不足する。実際に CO₂ が 280 → 555 ppm に漂流した）。

拘束は 2 つ:
1. 実際の風化の総和 `Σ min(kin, sup) = W0`
2. 供給律速になっている陸地面積の割合 = 目標値（既定 25%）

供給律速の割合は比 `S/K` だけで決まる（スケールに依らない）ので、
まず比を二分法で決め、そのあと総和が W0 になるよう両者を一緒にスケールする。

**(4) 較正値と挙動**

`W0 = 0.07 Gt-C/yr`（陸上）、`W_sf0 = 0.03`（海底）、`M_eff = 21 Gt-C/ppm`、
`S/K = 2.9`、供給律速 25%。回復時定数 **τ = 210 kyr**（1D: 220 kyr、文献 200–400 kyr）。

**火山脱ガスは独立なパラメータにしない。** 「現在の地球は定常である」が基準状態の定義なので、
`F_volc = W_land + W_seafloor` として基準状態から決まる量として扱う。

**(5) 回復には非対称性がある。**

910 ppm からの半減時間は、造山（侵食 2.5×）なら 0.06 Myr。
**壊すのは速く、直すのは遅い**という性質は 2 次元でも保たれている。

### 4.3 海底風化 🟢

陸上風化とは別個の重要な CO₂ シンク。海洋地殻の玄武岩が海水と反応して炭酸塩を固定する。

```
seafloorWeathering = W_sf0 · (CO2/280)^0.25 · exp((T − T0)/30)
較正値: W_sf0 = 0.03 Gt-C/yr
```

**定常条件 `F_volc = W0 + W_sf0` を必ず満たすこと。** これを閉じ忘れると定常 CO₂ が 280 ppm にならない。

陸上風化と依存性が違い、しかも**供給律速を受けない**ため、陸が完全に供給律速に落ちても
**最後の安全網**として働く。プロトタイプでは、陸上が供給律速でも海底風化により最終的に
280 ppm まで回復した（ただし極めて遅い）。水惑星シナリオを成立させるためにも必要。

### 4.4 火山脱ガス

```
F_volcanic = k · Σ(沈み込み帯の長さ × 沈み込み速度) + ホットスポット + LIP
```

**テクトニクス様式（§6.1）に直結する。** ヒートパイプ様式の初期惑星は脱ガスが極めて多い。プレート活動が止まった惑星は CO₂ 供給が止まり、風化に食われて凍る（＝火星の運命）。

### 4.5 酸素

```
d(O2)/dt = burial_organic_C · (32/12) − oxidation(還元性ガス, 硫化物風化, 呼吸)
```

**単調増加させない**（§02-3.1）。正のフィードバック（O₂ ↑ → 硫化物風化 ↑ → 硫酸 ↑ → 硫酸還元 ↑）を入れ、**オーバーシュートとクラッシュが出る系**にする。Lomagundi 事変（2.22–2.06 Ga）とその終焉（一次生産の崩壊）を再現できることが目標。

### 4.6 リン循環 ★

🟢 窒素は生物的に固定できるが、**リンは岩石風化からしか供給されない**。長期的な一次生産の上限はリンが決める。

さらに 🟡 **海洋の酸化還元状態がリンの再循環を制御する**:
- 貧酸素の海 → 堆積物からリンが放出される（**正のフィードバック**: 貧酸素 → リン放出 → 生産増 → 有機物分解 → さらに貧酸素）
- 酸化的な海 → リンは鉄酸化物に吸着して固定される

これが原生代の低酸素状態を長期間維持した機構とされる。また §02-3.4 の大量絶滅連鎖の④の駆動力でもある。

**帰結**: 「生物量を増やせばいい」ではなくなる。リンの供給（＝造山と風化）が生物圏の天井を決める。**テクトニクスが生命の量を支配する。**

## 5. 水循環

物理的な大気大循環は解かない。**3 セル循環を緯度プロファイルとしてハードコード**し、地形・大陸度・温度の修正を掛ける。安価で、かつ現実と同じ模様が出る。

### 5.1 基本降水プロファイル

```
P_base(φ) = P_eq · g(φ)
```
`g(φ)` は ITCZ（φ≈0、多雨）、亜熱帯高圧帯（|φ|≈25–35°、乾燥）、中緯度低圧帯（|φ|≈50–60°、多雨）、極（乾燥）を持つ形状関数。

### 5.2 修正項

| 修正 | 式 / 挙動 |
|---|---|
| 温度（蒸発量） | `× (1 + 0.07·(T̄ − 15))` |
| 大陸度 | 最寄り海岸からの距離で指数減衰 |
| 地形性降水 | 卓越風の風上斜面で増加、風下で**雨陰**。`ΔP ∝ max(0, wind · ∇elevation)` |
| 卓越風 | 緯度帯から決定（貿易風=東風、偏西風=西風） |
| 氷床 | 凍結セルは実効降水 0 |

### 5.3 流出・侵食・河川

```
runoff      = max(0, P − evapotranspiration)
erosionRate = k · runoff^m · slope^n     // ★stream power law。風化の供給律速に直結
```

- 標高の勾配に沿って流下方向を決め（D8 法）、上流から集水量を積算。
- **氷河侵食**を別枠で加える（氷床の縁で強い）。氷期には侵食が跳ね上がり、風化の供給が回復する。
- 内陸の窪地に溜まったら湖にする。

**`erosionRate` は §4.2 の supplyLimit の入力である。** 単なる地形の飾りではなく、惑星のサーモスタットを支配する量。

### 5.4 海面

```
seaLevel = f(氷床総量, 海洋地殻の平均年齢（若い＝熱い＝膨張）, 熱膨張, 海洋水量)
```

**海洋水量は定数ではない**（§6.5）。氷期の海面低下で陸橋ができ、種の分散経路が開く。

## 6. 固体地球

### 6.1 テクトニクス様式は時間発展する ★1990年には無かった軸

🔴 **プレートテクトニクスの開始時期に合意はない。** 推定は 40 億年前から 7 億年前まで分布する。専門家会合では約 3 分の 2 が「約 30 億年前」に同意したが、残りは 4.2 Ga 派と 10 億年前派に割れた。*Journal of the Geological Society* には端的に "We don't know when plate tectonics began" という論文がある。

**したがって、開始時期を定数にせず、マントルの熱史から創発させる。**

```ts
type TectonicMode =
  | 'magmaOcean'     // 固化前
  | 'heatPipe'       // Io 型。火山による熱輸送。地殻は下方に沈む
  | 'stagnantLid'    // 一枚蓋。沈み込みなし。大陸は成長しない
  | 'squishyLid'     // 部分的な移動性。ドリップ・サグダクション
  | 'mobileLid'      // プレートテクトニクス
  | 'dead'           // 冷却しきって停止
```

遷移はマントル温度（＝惑星の熱時計）で決まる:

```
dT_mantle/dt = (放射性崩壊による発熱 − 表面熱流量) / 熱容量
表面熱流量 = f(tectonicMode)   // 様式によって冷却効率が違う
```

| 様式 | CO₂ 脱ガス | 大陸成長 | 造山 | 風化サーモスタット |
|---|---|---|---|---|
| heatPipe | 極大 | なし | 低い火山地形 | **効かない**（新鮮岩石はあるが陸が無い） |
| stagnantLid | 中 | 停滞 | なし | 弱い |
| squishyLid | 中 | 緩慢 | 低い | 弱い |
| **mobileLid** | 中 | **速い** | **高い山脈** | **効く** ← ガイア成立の前提 |
| dead | ゼロ | 停止 | 侵食のみ | 効くが CO₂ 供給が無く凍結 |

**帰結**: 惑星の熱史がゲーム全体の時計になる。**「モバイルリッドに遷移できた惑星だけがガイアになれる」** — 逐次選択（§00-4 柱1）の物理的な裏付け。

サンドボックスではマントル初期温度・放射性元素量・粘性をスライダーで露出させる（🔴 なので）。

#### ★ 地形が二峰なのは【厚さ】ではなく【組成】の帰結（2026-08-28）

実装では長らく「厚さ 10km」を境に大陸と海洋を切り替えていた。これは
**物理が要求する状態変数（組成）を、代理の閾値で置き換えたもの**だった。

| | 大陸地殻 | 海洋地殻 |
|---|---|---|
| 岩石 | 花崗岩質 | 玄武岩質 |
| 密度 [g/cm³] | 2.75〜2.8 | 2.95〜3.0 |
| 厚さ | 35〜40 km | 7 km |
| 寿命 | **40 億年** | **2 億年未満** |

二峰性を作っている物理は 2 つだけ:

1. **アイリー均衡** 標高 ∝ t·(1 − ρ_c/ρ_m)。密度が違うので同じ厚さでも高さが違う。
   大陸 40×0.167 = 6.7km、海洋 7×0.106 = 0.74km。差 ≈ 6km = 地球の値
2. **リサイクルの非対称** 玄武岩質は重いので必ず沈む。花崗岩質は浮くので沈まない

さらに**それぞれの厚さも物理で決まる**:

- 海洋地殻 7km は海嶺の減圧融解（McKenzie & Bickle 1988）。
  **マントルポテンシャル温度が 20〜25℃ 上がるごとに 1km 厚くなる。**
  太古代（1500〜1600℃）では 14〜18km になり、海が浅くなる
- 大陸地殻 40km の上限はエクロジャイト化による下部地殻の剥落（デラミネーション）。
  チベットが 70km で止まる理由

**閾値方式の帰結**: 島弧が海底に作る薄い被膜が 10km を越えた瞬間に「大陸」に
化けて二度と沈み込まなくなり、厚さ 10〜25km の不滅の帯（面積の 35%）が溜まる。

`felsic` の場（0=玄武岩質 / 1=花崗岩質）として実装済み。
**`crustComposition` = 1 で有効。既定は 0**——保存量と玄武岩の循環は閉じたが、
珪長質が discrete な大陸に濃縮しない（惑星全面が厚さ 25km になる）。
経緯と実測は WORK-IN-PROGRESS.md。

### 6.3 LLSVP と LIP ★大量絶滅を予測可能にする

🟢 核-マントル境界に **LLSVP（大規模低速度領域）**が 2 つある（"Tuzo" と "Jason"、アフリカ下と太平洋下）。その縁が **PGZ（プルーム生成帯）**で、**LIP の噴出位置は PGZ の直上に集中する。**

```ts
interface Planet {
  llsvp: Array<{ centerLon, centerLat, radius }>  // 惑星の固定構造。プレートと共に動かない
}
```

**帰結 ★**: LIP をランダムイベントにしない。**大陸が LLSVP 縁の上を通過したときに LIP が起きる。**

- 大量絶滅が**予測可能**になる。プレイヤーは数千万年先の危機を見て、大陸を逃がすか、生物圏を強靭化するかを選べる。
- ランダム災害が**戦略**に変わる。これは SimEarth に対する明確な改善。
- 顕生代のビッグファイブのうち 4 つが LIP 由来 🟢 なので、科学的にも正しい。

### 6.4 超大陸サイクル 🟢

プレート運動をランダムウォークさせず、**集合と分裂を繰り返す 300〜500 Myr 周期**のアトラクタを持たせる。

既知の超大陸: ヌーナ/コロンビア (1.8–1.3 Ga)、ロディニア (1.1–0.75 Ga)、パンゲア (0.33–0.17 Ga)。集合様式には introversion / extroversion / orthoversion がある 🟡。

超大陸期の帰結:
- 内陸乾燥、生物多様性低下
- **平坦化 → 侵食低下 → 風化が供給律速へ → サーモスタットの弱化**（§4.2）
- 分裂期: 海岸線増加、侵食増加、サーモスタット復活、多様性増加

**これがゲームに長周期のリズムを与える。**

### 6.5 深部水循環・深部炭素循環 🟡 ★1990年には無かった

沈み込むスラブは水と炭酸塩をマントルに運ぶ。マントル遷移層（ワズレアイト/リングウッダイト）は**海洋数杯分の水を保持できる**。地球の海水量は数十億年スケールで**減少している可能性**がある。

```
d(water.ocean)/dt = 火山からの脱ガス − 沈み込みによる持ち去り
```

**帰結**: 海洋量を定数にしない。長期的に海が干上がる惑星、逆に水惑星化する惑星が作れる。同じ機構で炭素も扱う（沈み込んだ炭酸塩の一部だけが弧火山から戻る）。

### 6.5b 大陸地殻の収支 ★45 億年通して初めて分かったこと

M4 の合格条件（21/21）を満たした時点では、まだ **45 億年通すと壊れた**。
全史ランで判明した収支の問題を記録する。**どれも数百 Myr のテストでは見えない。**

| 症状 | 原因 | 対処 |
|---|---|---|
| 体積が 4.3 倍、陸地 100% | **造山が無から地殻を作っていた** | 造山は水平短縮なので**局所的に体積保存**にする（周囲の前縁から引き寄せる） |
| 体積を上限で押さえたら陸地が 1〜5% に | 一様な割り戻しが厚さ分布を平坦化し、閾値ぎりぎりのセルが大陸から外れる | 超過分は**厚いセルから優先して**削る |
| 陸地が 0.3% まで崩壊 | `RIFT_FLOOR (9km) < continentThreshold (10km)`。リフティングを受けた縁が大陸から外れ、**面積の供給源が消えていた** | `RIFT_FLOOR` は必ず閾値より上に（13km）。大陸面積は「衝突で減り、伸張で増える」で釣り合う |
| 体積は保存されるのに陸地だけ減る | 堆積が**深海平原まで一様に配られ**、削れた大陸地殻が海盆に流出して戻らない | 水深の 4 乗で重みを落とし、**薄化した大陸地殻（棚と斜面）に限る** |
| 10 億年で大陸が消える | 侵食に**基準面の効果**が無く、低平な楯状地も高山と同じ速さで削れる（0.015mm/yr × 1Gyr = 15km） | 削剥を**標高に比例**させる。削れるほど遅くなり自己制限する |
| 海水が +32% | 沈み込みの正規化係数が過大で `activity` が 0.17 にしかならず、脱ガスが勝つ | 沈み込み帯の実面積（全球の数 %）で正規化する |
| LIP が 125 回（地球は 20〜30 回） | `lipRate` が 4 倍大きい | 1e-9 に下げて 27 回 |

> **教訓: 保存則を持つ量は、必ず「作る側」と「消す側」を明示的に対にすること。**
> 造山・堆積・島弧の 3 つはいずれも地殻を動かすが、
> **正味の体積が増えてよいのは島弧の付加だけ**であり、その速度は
> 目標体積（地球は 7.2e9 km³）に向かって飽和する。
> これを最初から意識していれば 5 回の手戻りは避けられた。

### 6.5c ★最長の遠回り — 症状の subsystem を疑って 7 つの仮説を外した

「45 億年通すと陸地が 0.2% ↔ 35% で暴れる」という症状から出発して、
**地殻の機構を 7 つ疑い、7 つとも実験で否定した**。
最終的な原因は地殻ではなく `SimLoop` の時間刻みの打ち切りだった。
同じ遠回りを繰り返さないために、過程をそのまま記録する。

#### 否定した仮説（すべて 45 億年ランで検証）

| # | 仮説 | 検証方法 | 結果 |
|---|---|---|---|
| 1 | 堆積の受け皿が海洋地殻を含む | 閾値を 0.45→1.3 で掃引 | **部分的に正**（沈んだ大陸の帯は消えた）が振動は残る |

**(a) 地殻は健全だった**

| 指標 | モデル | 地球 |
|---|---|---|
| 陸% 中央値 | **29.1%** | 29.2% |
| 大陸地殻の厚さ標準偏差 | **8.1 km** | 6〜8 km |
| 厚さ分散の収支（正味） | +0.01 /step（ほぼ釣り合い） | — |

**45.4 億年のうち 44.6 億年は陸 29% 前後で安定していた。**
破綻していたのは**最後の 8000 万年だけ**。

**(b) 指標が間違っていた ★これが遠回りの直接の原因**

`直近 2Gyr の max − min` だけを見ていた。この指標は
「20 → 30 → 20」（振動）と「20 → 30」（ドリフト）を区別できない。
自己相関を取ったら**周期のピークが一切立たなかった**（lag1 ≈ 1.00、ピーク相関 −0.00）。
振動ではなかった。

さらに**最終値という単一サンプル**で seed 間比較をしていた。
実際の分布は P5 13.9% / P50 29.1% / P95 33.8% で、
「0.2%」も「35%」も裾を引いていただけだった。

**(c) 真の原因は `SimLoop` の時間刻みの打ち切り**

```ts
// 誤り: 上限に当たると dt が膨らむ
let substeps = Math.ceil(yearsRequested / stepYears)
if (substeps > MAX_SUBSTEPS) substeps = MAX_SUBSTEPS
let dt = yearsRequested / substeps        // 400万年/16 = 25万年
```

炭素循環は応答時定数 20 万年に対し希望刻み 2.5 万年。
だが 1 ティックで 400 万年を要求すると **dt が 25 万年（時定数より粗い）**になっていた。
**コメントには「上限に当たったら進行年数を減らす」と書いてあり、コードだけが違っていた。**

刻み依存性を測って発覚した:

| 刻み | ステップ数 | T 標準偏差 | 最終 T |
|---|---|---|---|
| 0.5 Myr | 9080 | **2.7 K** | 20.9℃ |
| 1 Myr | 5675 | 43.8 K | 72.0℃ |
| 2 Myr | **5675** | 43.8 K | 72.0℃ |
| 4 Myr | **5675** | 43.8 K | 72.0℃ |
| 8 Myr | **5675** | 43.8 K | 72.0℃ |

**1〜8 Myr がステップ数まで完全に同一** = 全部が上限に張り付いていた証拠。
0.5 Myr だけが抜けられて、標準偏差が **16 分の 1** に落ちる。

> **教訓 1: 収支が合っていても、刻みが粗ければ嘘の力学が出る。**
> 収支監査だけでなく、**数値解法の妥当性（刻み依存性・解像度依存性）も常設の計測項目にする。**

> **教訓 2: 症状が出ている subsystem が、壊れている subsystem とは限らない。**
> 陸地面積で症状が出たので地殻を 7 回疑ったが、壊れていたのは時間積分だった。
> 機構を疑う前に、**全 subsystem の収支を並べて、どれが釣り合っていないかを先に見る。**

> **教訓 3: 単一サンプルと max−min で判断しない。**
> 平均・中央値・標準偏差・分位点・自己相関・卓越周期を出す。
> 「振れ幅」だけでは振動とドリフトを区別できない。

| # | 場所 | 症状 | 修正 |
|---|---|---|---|
| 1 | `SimLoop` の刻み打ち切り | 上限に当たると `dt` が希望刻みの 10 倍に膨らむ | 進行年数の方を減らす |
| 2 | `SimLoop` の発火量 | 溜まった `acc` をそのまま渡していた（可変） | 希望刻みぴったりで発火し端数は持ち越す |
| 3 | `World.advance` の結合間隔 | **気候と炭素の結合間隔＝呼び出し側の刻み** | 50 kyr で上限 |
| 4 | `erodeAndDeposit` | 堆積が**海面より上まで積み上がる** | 収容可能量（海面）で頭打ち |

#### #3 が最も深刻だった — フレーム時間で物理が変わる

`World.advance` は `loop.advance()` で全サブステップを回した**後に**気候を 1 回だけ解いていた。
つまり気候と炭素の結合間隔が、呼び出し側の要求年数そのものだった。

ワーカーは `years = yearsPerSecond × 実測フレーム時間` で進めるので、
**マシンの速さで物理が変わる**。風化は温度に指数で依存するため誤差が効く。

実測（CO₂ 4 倍の摂動からの回復、300 万年後の CO₂。較正の定常値は 280 ppm）:

| 結合間隔 | 修正前 | 修正後 |
|---|---|---|
| 5〜50 kyr | 306〜311 ppm | 306〜311 ppm |
| 60〜250 kyr | **302〜624 ppm** | **308.5〜313.0 ppm** |
| ばらつき | 2 倍 | **1.5%** |

`CLIMATE_COUPLING_YEARS = 50_000` は感覚ではなく、**収束が確認できた帯域の上端**から取った。

**帰結: GPU 移植の位置づけが変わった。** 結合間隔 50 kyr を守ると
最高速 200 万年/秒では毎秒 40 回の気候ソルバが要る。
CPU（12ms/solve）ではフレーム予算の 48% を占める。
GPU は「あれば速い」ではなく、**物理的に正しい結合間隔を保ったまま最高速を出す条件**である。

`World.climateCouplingYears` で緩められる。CO₂ の平衡値を検証しないテスト
（テクトニクスの体積収支、水循環）は 500 kyr にして速くしている。
**「速いから緩める」ではなく「そのテストが何を検証しているか」で選ぶこと。**

#### #4 はテストが捕まえた

プレートが止まった惑星（造山が無い）で最高標高が 3.5 km → 6.5 km に育った。
堆積の配分に上限が無く、大陸棚を海面より上まで積み上げていた。
沖合の堆積物は波浪限界より上には積めないので、**収容可能量は有限**である。

副次的に体積クランプの発動量が **−209.6 → −9.2**（20 分の 1）になった。
超過そのものが減ったので、設計上疑わしかったクランプが実質的に働かなくなった。

#### テストにも同じ指標の問題があった ★

2 本とも「**変動する量の終端値を 1 点比較**」していた。

- 「衝突で山ができる」→ 3 億年時点がたまたま谷だった
  （走行中は 4463 m まで育つのに終端は 3371 m）。**走行中の最大値**で見るべき
- 「進行年数が抑えられ、それが報告される」→ #1〜#3 の修正で
  抑えられなくなったのが正しい挙動。**時間が黙って捨てられないこと**を検証すべき

> **教訓 4: テストも「何を測っているか」を設計する。**
> 本体の解析で単一サンプルと max−min を戒めておきながら、
> テストが同じ誤りをしていた。変動量には走行中の統計を使う。

### 6.5e 総合監査 `npm run audit` ★この調査から生まれた道具

6.5c/6.5d の調査で 7 つの不具合を見つけたが、**どれも保存則を一切破っていない**。
体積も炭素も 1kg もこぼさずに、力学だけが嘘だった。
しかも症状が出た subsystem（陸地面積）と壊れていた subsystem（時間積分）が違った。

バラバラのスクリプトを 20 分ずつ走らせて 1 つずつ潰す方式は遅すぎたので、
**1 本のランで全 subsystem を同時に見る道具**を作った。

```bash
npm run audit             # 全史 4.54Gyr（結合間隔 200kyr、約 6 分、16 項目）
npm run audit -- --full   # 既定の結合間隔 50kyr で厳密に（約 20 分）
npm run audit -- --quick  # 数値解法の検査だけ（約 3 分）
```

#### 検査の 4 分類 — なぜこの 4 つか

| 分類 | 検査 | **なぜ要るか（今日の実例）** |
|---|---|---|
| **A. 収支** | エネルギー / 炭素 / 水 / 地殻 | 作る側と消す側が対になっているか（6.5b の原則） |
| **B. 停止検出** | 各機構が何 % のステップで作動したか | **`scale = 0` で侵食が 20 億年停止していた。保存則を一切破らないので収支監査では永久に見つからない** |
| **C. 数値解法** | 刻み依存性 / 解像度依存性 / 進行年数 | **収支が完璧に閉じたまま、刻みが粗いと嘘の力学が出る** |
| **D. 軌跡統計** | 中央値・P5・P95（終端値ではない） | **単一サンプルと max−min では振動とドリフトを区別できない** |

**B が今日いちばん高くついた項目である。** 収支監査だけを常設にしていたら、
侵食が丸ごと死んでいることに気づけなかった。
「機構が黙って死ぬ」経路は、保存則とは独立に検査する必要がある。

#### 道具は作った初回に元を取った

`npm run audit` を書いて最初に回した 1 回で、**前日に自分が書いたコードの単位バグ**を検出した。

```
地殻体積の収支  変化 6.35e9  説明 -838025.14e9  残差 838031.49e9 km³
   内訳 ... 深海流出 -838026.49        <- 地殻全体が 6e9 km³ なのに 83万 e9
```

`lost += want * a` の `a` が m² のまま（他の台帳項目は `/1e6` で km² に直している）で
100 万倍になっていた。**このバグを持ったまま「設計 A は失敗」と判断していた。**

続けて 2 つ目も出た。`sedimentLoss` は `erodeAndDeposit` の前後で測る `erosion` に
既に含まれているので、合計に足すと**二重計上**になる。
侵食 −0.775 と深海 −0.775 が完全に同じ値だったのが決め手。
内訳としては意味があるので、合計から外して表示専用に再分類した。

> **教訓 5: 台帳に項目を足すときは、既存の項目と重なっていないかを確認する。**
> 「作る側と消す側を対にする」だけでなく、**同じ損失を二度数えていないか**も見る。

#### 現在の結果（2026-08-27）

16 項目 / PASS 11 / WARN 5 / FAIL 0。

| 分類 | 状態 |
|---|---|
| エネルギー収支 | ✓ 中央値 5.5e-5 W/m² |
| 炭素収支 | ✓ 中央値 9.4e-4 |
| 水収支 | ✓ 変化 = 沈み込み + 脱ガス + clamp で厳密に一致 |
| 地殻体積の収支 | ! 残差あり（造山の体積中立性が未計上） |
| 停止検出 | ✓ 5 機構すべて 95〜100% で作動 |
| 数値解法 | ✓ 進行年数・解像度 / ! 刻み依存 13.7% |
| 軌跡 | ✓ 気温 16.8℃ / ! 陸 3.6%・CO₂ 12462ppm |

**残る実質的な問題は「陸地面積の中央値 3.6%（地球 29.2%）」の 1 点**で、
CO₂ が高いのはその帰結である（風化容量が足りない分を海底風化が肩代わりし、
海底風化は CO₂ の関数なので高い CO₂ が必要になる。6.5c 参照）。

そして原因は**測定可能な 1 つの数字**まで絞れた。

| | モデル | 地球の実測 |
|---|---|---|
| 島弧による大陸地殻の生成 | 0.35 km³/yr | 1〜3 |
| 深海流出による損失 | 0.78 km³/yr | 1〜2 |
| **比** | **1 : 2.2** | **1 : 0.7** |

桁は合っており、**比が 3 倍ずれている**。
次は `dVc/dt = 生成 − 消失` を**文献値で較正する**（目標体積に合わせるコントローラをやめる）。
基準が外にあるので、症状に合わせて当てにいく作業にはならない。

## 6.7 海洋循環（実装済み 2026-08-28。`src/sim/ocean.ts`）

### なぜ生命より先か

生命を先に作ってから海洋を足すと、生命側を書き直すことになる。
一次生産の分布・栄養塩・溶存酸素・炭素の隔離は、どれも海洋循環が決める。

| 生命側で必要なもの | 海洋循環がないと |
|---|---|
| **一次生産の分布** | 「日射 × 温度」だけで決まる嘘になる。外洋の 9 割は栄養塩の砂漠で、生産が集中するのは**深層水が湧く場所**だけ（東岸境界流・赤道発散・南大洋） |
| **リンの循環** | 長期の律速はリン（§3.3）。陸の風化が供給し、**湧昇が再循環**する |
| **海洋無酸素事変** | 大量絶滅の主要因の一つ。深層の換気が止まる → 硫酸還元菌が H₂S（docs/02-3.4 のメデア機構）。**循環の停止そのものが機構**である |
| **生物ポンプ** | 現状 CO₂ は大気のスカラー 1 個だけ。**実際の海洋は大気の 60 倍の炭素を持つ**。生命が炭素を深海へ隔離する経路が作れない |
| **熱水噴出孔** | 生命の起源地の候補（docs/02-2.8）。鉄律速の外洋への鉄供給源でもある |

熱塩循環は `docs/03-3.3` の惑星健全性 9 軸レーダーにも既に入っている。

### どこまで作るか — 3 次元海洋大循環モデルは不要 🟢

**海洋循環の調整時間は約 1000 年**で、本作のタイムスケール（10⁵〜10⁹ 年）から見れば
気候と同じく**準静的**である。時間積分ではなく**平衡解を解けばよい**。
1 セル 313km（128×64）では中規模渦も解けないので、3D GCM は過剰かつ無意味。

### 構成（3 つの部品）

#### (a) 風成循環 — スヴェルドラップ平衡 🟢

```
β·V = curl(τ)/ρ                 Sverdrup 1947
西岸境界流で戻る                  Stommel 1948 / Munk 1950
エクマン湧昇 w_E = curl(τ/f)/ρ
```

出力: 環流の配置、西岸境界流（黒潮・湾流）、**湧昇マップ**

> **★訂正（2026-08-28）: PCG は流用できないし、その必要も無い。**
>
> ここには「流線関数を解く楕円型方程式なので気候ソルバの PCG が使える」と
> 書いてあったが、**Stommel の渦度方程式 `R∇²ψ + β∂ψ/∂x = curl τ/ρ` は
> β 項のせいで非対称**で、PCG の前提（対称正定値）を満たさない。
> BiCGSTAB などが要る。
>
> だが**そもそもソルバが要らない。** スヴェルドラップ解は東岸（ψ=0）から
> 西へ 1 回積分するだけで厳密に出て、西端に残った ψ がそのまま
> 西岸境界流の輸送量になる。反復もしないので速い。
>
> 実装で踏んだ罠（`src/sim/ocean.ts` に詳細）:
> - **エクマン輸送の 1/f は `f/(f²+f_min²)` で正則化する。** `|f| >= f_min` で
>   頭打ちにすると赤道で M が跳び、跳びの表し方で総湧昇が 60% 変わった
> - **発散は有限体積で書く。** 中心差分だと ∫∇·M dA が境界項にならない
> - **陸に接する面はフラックス 0。** 近似ではなく正しい境界条件で、
>   沿岸湧昇はここから出る
> - **東岸の赤道向き風は 3 セル循環からは出てこない。** 亜熱帯高気圧の
>   東縁という陸海コントラストの効果なので、パラメタライズして足す。
>   これが無いと東岸湧昇（ペルー・ベンゲラ・カリフォルニア）が出ない

#### (b) 熱塩循環 — 2 箱モデル 🟢

```
強度 ∝ 高緯度と低緯度の密度差（水温と塩分）    Stommel 1961
```

**ヒステリシスを持つ**（淡水流入や温暖化で一度止まると戻らない）。
これがそのままティッピング要素になり、介入で操作できる。

出力: 深層の換気速度 → **深層の溶存酸素** → 無酸素事変の判定

#### (c) 海底熱水 — 既存の場から導出 🟢

```
熱水フラックス ∝ 海嶺の拡大速度（= divergence の正の部分）
```

**新しい計算はほぼ要らない。** `divergence` と `volcanism` の場は既にある。
使っていないだけである。

### 追加する場

| 場 | 単位 | 由来 |
|---|---|---|
| `oceanU` / `oceanV` | m/yr | (a) |
| `upwelling` | m/yr | (a) のエクマン湧昇 |
| `dic` | mol/m³ | 溶存無機炭素。溶解ポンプ + 生物ポンプ |
| ~~`o2Ocean`~~ | mol/m³ | **場にしなかった。** 生命がいないと空間構造が出ない（一様な場は飾り）。全球スカラー `deepOxygen` / `surfaceOxygen` で持つ |
| ~~`phosphate`~~ | mol/m³ | **同じ理由で場にしなかった。** 代わりに `phosphateSupply` [mol-P/m²/yr]（湧昇 × 深層濃度）を場にした。**一次生産が要るのはこちら** |
| `ventFlux` | **W/m²** | (c)。相対値ではなく物理単位で持つ（docs/04-8.8） |

> **DIC はまだ診断であって、大気の CO2 を動かしていない。**
> `carbon.ts` は `Meff = 21 Gt-C/ppm`（大気 + 海洋の実効リザーバ）で CO2 を
> 積分しており、海洋の緩衝は集約された定数として既に入っている。
> 実装した DIC の `impliedMeff` は 20.8 でこれと一致するので、両者は
> 同じことを言っている。**prognostic にする（Meff を捨てる）のは M5 の直前。**
> 生物ポンプが炭素を深層に隔離して大気 CO2 を下げる経路にはそれが要る。
> ただし Meff が状態依存になり、冥王代の CO2 10 万 ppm では 21 → 2.2 に落ちる
> （高 CO2 では炭酸系の緩衝が効かない）。**冥王代・太古代の CO2 の応答が
> 10 倍速くなる**ので、全史ランでの検証込みで別に取り組むこと。

### 6.6 気候 → テクトニクス ★逆向きの矢印

設計初期は「テクトニクス → 気候」の一方向だと考えていたが、**逆向きの結合が3本ある**。
いずれも実在し、うち1つはゲームの敗北条件の構造を変える。

#### (a) 地表温度 → テクトニクス様式 🟡 ★最重要

Lenardic らの一連の研究:

> **プレートテクトニクスは低い地表温度で、スタグナントリッドは高い地表温度で成立する。**
> 400–600 K の地表温度は、①対流応力の低下、②鉱物の粒成長の加速、③熱亀裂の抑制
> によってスタグナントリッドを引き起こしうる。金星の 750 K は「余裕で停止させられる」水準。

論文タイトルがそのまま *"A climate induced transition in the tectonic style of a terrestrial planet"*。

**必要な温度変化が大きいことに注意。** CO₂ を数倍にする程度（3–10 K）では届かない。
**暴走温室級（数十〜100 K）**でないと様式は動かない。プレイヤーが「少し温暖化させる」では効かない。

温度より効く経路がもう一つある — **水の喪失**。水はリソスフェアを弱める（蛇紋岩化、
かんらん石の含水弱化）。暴走温室 → 水の宇宙散逸 → 乾いたリソスフェアが強くなりすぎて沈み込めない。
金星の最有力説はこちら。§6.5 の深部水循環と接続する。

**そしてヒステリシスがある** 🟡:

> スタグナントリッドの初期条件からプレートテクトニクスを開始させるのは、
> 既に動いている惑星でそれを維持するより難しい。
> **プレートテクトニクスを失った惑星が後から再開する見込みは薄い。**

実装:
```
mantleModel.surfaceTemperature = climate.globalMeanT   // 結合
lithosphereStrength = f(surfaceTemperature, waterContent)
// mobileLid -> stagnantLid の遷移閾値と
```

#### (b) 氷床 → 火山活動 🟢 桁で効く

アイスランドでは最終氷期後の脱氷直後に**噴火率が現在の 30–50 倍**になり、1000 年以上継続した
（約 3,100 km³ のマグマ）。機構は氷の荷重除去による**減圧融解**で、マントルの融解度は圧力に敏感。

全球でも脱氷期の火山活動増加が報告されており、火山記録にミランコビッチ周期が見える。
イエローストーンでは脱氷によるマントル CO₂ フラックス増加が**正の気候フィードバック**を作る。

```
volcanicFlux *= 1 + k_unload · max(0, -d(iceLoad)/dt)
```

**これは閉じた正のフィードバックを作る:**

```
脱氷 → 荷重除去 → 火山増 → CO₂ 増 → 温暖化 → さらに脱氷      （正）
氷床成長 → 荷重 → 火山抑制 → CO₂ 減 → 寒冷化 → さらに氷床成長  （正）
```

時間スケール 10³ 年。**ゲーム内で最も速い「気候 → 固体地球」のフィードバック。**

> **§3.7 の記述を修正する必要がある。**
> 「全球凍結すると風化が止まり、火山 CO₂ が蓄積して自力脱出する」と書いたが、火山側が甘い。
> スノーボールでは全大陸が氷床に覆われるため、**大陸火山は荷重で抑制される**。
> CO₂ 蓄積は想定より遅く、**脱出が難しくなる**。
> ただし中央海嶺は海の下なので抑制されず、脱出経路は残る。
> ゲーム的にはむしろ良い（シナリオ #5 の難度が上がり、脱出が達成感になる）。

おまけ: 氷河荷重の除去は**地震も起こす**（フェノスカンジアの氷河後期断層、Pärvie 断層 約150 km、M8 級）。

#### (c) 降水 → 侵食 → 風化供給 🟡 ★M3 で符号が逆と判明。訂正する

臨界テーパー楔理論により、侵食で質量が除去されると応力状態が変わり、楔が変形して
岩石が上昇する。降水が片側に偏ればその側の削剥が加速する
（ヒマラヤの "tectonic aneurysm" — Namche Barwa、Nanga Parbat）。ここまでは 🟢。

**当初、これを「気候が自分でサーモスタットを自己修復する負のループ」と書いた。M3 の実装で測ったら符号が逆だった。**

2 次元モデルで温暖化させて、供給側と需要側の温度感度を直接比べた結果:

| | 温度感度 |
|---|---|
| **供給**（侵食 → 新鮮岩石の露出） | **3.7 %/K** |
| **需要**（速度論律速の風化、`exp(ΔT/13.7)`） | **7.6 %/K** |

**需要が供給の 2 倍速く増える。** 結果、温暖化すると供給律速の面積が
**増える**（29.2% → 30.7%）。つまり:

> **暑い惑星ほどサーモスタットが弱い。**

これは温暖化に対する**正のフィードバック**（不安定化）であって、当初書いた負のループではない。

**なぜこうなるか**: ケイ酸塩風化の活性化エネルギーによる温度依存は 7〜8 %/K で、
これは確立した値。一方、降水はエネルギー律速で 2〜3 %/K しか増えず、
しかも蒸発散も増えるので流出はさらに鈍い。侵食は流量の平方根で効くのでもっと鈍る。

🟡 **文献との整合**: これは §4.2 で 🟡 として挙げた
「熱力学的制約下では風化速度が温度上昇で減少しうる（正のフィードバックに反転する）」
と同じ機構である（Maher & Chamberlain、Winnick & Maher）。
2 次元モデルが独立にこれを再現したことになる。

**造山は逆向きに効く。** 同じ +18% の侵食増でも:

| 経路 | 供給律速の面積 |
|---|---|
| 温暖化による侵食増 | 29.2% → **30.7%**（悪化） |
| 造山による侵食増 | 29.2% → **28.7%**（改善） |

造山は**供給だけ**を増やすので比が正しい向きに動く。
気候は供給と需要を同時に上げるので、需要が勝って符号が逆転する。

**ゲーム設計への含意**: プレイヤーの「造山を促す」介入（§03-2.2）は、
「惑星を冷やす」介入とは**質的に違う**。前者はサーモスタットそのものを直し、
後者は症状を抑えるだけで、むしろサーモスタットを弱める。
この違いを寄与分解パネルで読めるようにすること。

#### (d) 噴火 → プレート運動 ❌ ほぼ効かない

単発の噴火ではプレートは動かない。エネルギースケールが違いすぎる。例外は LIP / プルーム級:

- **プルームによる大陸分裂の開始** 🟡 — CAMP とパンゲア分裂、デカンとインド–セーシェル分離、アファール。
  因果の向き（プルームが割ったのか、割れ目にプルームが来たのか）は議論中
- **プルーム誘起沈み込み開始** 🟡 (Gerya et al. 2015) — プルームがリソスフェアを薄化・弱化させ、
  沈み込みを開始させる。**太古代の最初のプレートテクトニクス開始機構の候補**

後者は §6.1 の様式遷移に直接効く。
**「スタグナントリッドの惑星で、プレイヤーが巨大噴火を起こしてモバイルリッドへの遷移を促す」
という介入が科学的に正当化できる。** シナリオ #3「一枚蓋の惑星」の攻略手段になる。

**ガイアの正体は 3, 4, 5, 6, 8 の負のループが 1, 2, 7, 9, 10, 11 の正のループに勝つことである。**
勝てば惑星は自己調節する。負ければスノーボール・金星化・大量絶滅に落ちる。
**これは所与ではなく、勝敗の分かれる勝負である。** — これが本作の設計の全体像。

そして **ループ 11 だけが不可逆**である。他はすべて、条件が戻れば元に戻りうる。
暴走温室だけが惑星の駆動系そのものを永久に殺す（§03-3.1）。
