# 03. ゲームプレイ

> 科学的な根拠は [06-science-basis.md](06-science-basis.md)、設計の背景は [00-concept.md](00-concept.md) を参照。

## 1. プレイヤーは何者か

**惑星の恒常性そのもの。** 神ではない。惑星の外側から万能に介入するのではなく、惑星が持つ自己調節能力の「意志」を演じる。

ただし現代のガイア理論では、その意志は目的を持たない（§00-2）。**プレイヤーは逐次選択の試行そのもの**である。安定を目指すが、達成できるとは限らない。

この立場設定が Ω 経済（§2）とメタ進行（§7）の両方に直結する。

## 2. Ω（ガイア・ポイント）経済

### 2.1 中核ルール

```
Ω_regen = Ω_base × homeostasisIndex × biosphereIndex
```

| 指標 | 定義 |
|---|---|
| `homeostasisIndex` | 気候が長期的にどれだけ安定しているか。全球平均気温の直近ウィンドウでの分散の逆数（0..1 に正規化） |
| `biosphereIndex` | 総バイオマス × クレード多様性（シャノン指数）。0..1 |

**帰結:**
- 惑星を暖めすぎ / 冷やしすぎると Ω 回復が落ち、修正する手段が減る → **破壊は自己懲罰的**。
- 生命が豊かなほど強い介入ができる → **育成が報われる**。
- 「何もしないでいると Ω が溜まる」ので、**待つことが戦略になる**。SimEarth の「見ているだけの時間」を、能動的な資源蓄積に読み替える。

Ω 上限も `biosphereIndex` に比例させる。序盤の不毛な惑星では小さな介入しかできない。

### 2.3 介入の遅延

**すべての介入は即座には効かない。** マントル操作は数億年、プレート操作は数千万年、種まきは数万年、啓示は数百年。
プレイヤーは常に「今の惑星」ではなく「数ティック後の惑星」に向けて打つ。これが本作の戦略性の核。

UI 上は**予測ゴースト**（このまま行くと気温がどう推移するかの薄い予測線）で支援する。

## 3. 勝敗条件

### 3.1 敗北

> **「金星化」と「動かない星」は同じ経路でつながっている** ★
>
> 設計初期は別々の敗北条件として並べていたが、§01-6.6a の climate-tectonic coupling により
> **暴走温室はプレートテクトニクスを停止させ、しかもヒステリシスで再開できない**ことが分かった。
>
> つまり「暑くしすぎた」という一見可逆な失敗が、**惑星の駆動系そのものを永久に殺す**ところまで行く。
> UI 上も、暴走温室が近づいたら「これは戻せない種類の失敗である」と明示的に警告する。

敗北時は**タイムラインの再生**と「どこで分岐したか」の解説を出す。負けが学習になるように。
そして**敗北した惑星は捨てられない**（§7）。

### 3.2 勝利 — ガイア・プロトコル

**恒常性は状態ではなく履歴で判定する。** 逐次選択（§00-2）の実装として、すべての段階が「擾乱を受けて回復した」という実績を要求する。

| 段階 | 条件 |
|---|---|
| **0. 生命** | LUCA 相当のクレードが成立し、10 億年持続 |
| **I. モバイルリッドへの遷移** | プレートテクトニクスが成立し、大陸が成長し始める（§01-6.1） |
| **II. 恒温性の確立** | 風化サーモスタットが機能し、**外部強制を 3 回受けてその都度 1 億年以内に平衡へ復帰**。単に温度が安定しているだけでは不可 |
| **III. 酸素惑星** | O₂ > 15% を維持し、陸上生物圏が確立。ただし**オーバーシュートとクラッシュを経ている**こと |
| **IV. 多様性の頑健性** | 大量絶滅を 3 回経験し、その都度クレード多様性がシャノン指数で回復 |
| **V. 知性の到達** | 社会が成立し、`energyCapture` が化石燃料依存の水準を通過 |
| **VI. プロトコルの継承** | `gaiaAwareness > 0.8` の社会が、**9 つのプラネタリー・バウンダリーすべてを安全域に戻し**、1 万年維持 |

段階 VI に到達すると、**プレイヤーの Ω が文明に移譲される演出**でエンディング。惑星は自分でガイアを続ける（Gaia 2.0、§02-4.8）。

### 3.3 惑星健全性 — 9 軸レーダー ★

単一の「ガイアゲージ」は 1990 年的である。現代の枠組みは **プラネタリー・バウンダリー**（Rockström et al. 2009 / Richardson et al. 2023）— 9 つの独立した境界であり、現実の地球では既に **6 つが越えられている**。

```
        気候変動
    新規化学物質  ●  生物圏の一体性
        ●              ●
  オゾン層 ●        ● 土地利用変化
        ●              ●
   大気エアロゾル  ●  淡水利用
        海洋酸性化   生物地球化学的フロー (N/P)
```

**多次元であることが現代的な理解である。** プレイヤーは「1 つの数字を上げる」のではなく、**トレードオフの中で妥協点を探す**。CO₂ を下げるために大規模な植林をすれば土地利用境界を越える、といった葛藤が生まれる。

## 3.4b 時間の刻み — 固定 tick にする ★決定論の完成形

### 現状の問題

```js
const years = yearsPerSecond * dtWall   // dtWall = 実測フレーム時間
world.advance(years, INTERACTIVE)
```

**進める年数がフレーム時間に依存する小数**になっている。
docs/01-6.5d で「気候と炭素の結合間隔がフレーム時間依存」を直したが、
**tick 自体はまだ小数のまま**である。ここを閉じないと、
生命の結果もマシンの速さで変わる。

UI 表示も `1.234 kyr/秒` のような半端な数字になっていて、
プレイヤーが「いま何年進んだか」を把握できない。

### 物理から来る制約

**気候と炭素の結合間隔 50,000 年**が原子単位である（docs/01-6.5d の測定で決定）。
これより粗い刻みで進めると CO₂ が最大 2 倍ずれる。

したがって:

- **1 tick = 5 万年が上限**
- それ以上速くしたければ**1 秒あたりの tick 数を増やす**
- tick 1 回につき気候ソルバ 1 回（CPU 12ms）なので、**毎秒 80 tick が計算上の天井**

### 速度段階

| 段階 | 年/tick | tick/秒 | 年/秒 | 45.4 億年の所要 |
|---|---|---|---|---|
| 超低速 | 10 | 20 | 200 | — |
| 低速 | 100 | 20 | 2,000 | — |
| 標準 | 1,000 | 20 | 20,000 | 63 時間 |
| 高速 | 10,000 | 20 | 200,000 | 6.3 時間 |
| 超高速 | 50,000 | 20 | 1,000,000 | 76 分 |
| 最高速 | 50,000 | 40 | 2,000,000 | 38 分 |

小数点は出ない。表示は `1,000 年/tick × 20/秒` とする。

`EPOCHS` の `baseYearsPerSecond`（冥王代〜原生代 50 万/秒、顕生代 10 万/秒、
人新世 1 年/秒）は、**エポックごとの「既定の速度段階」**に読み替える。

### ★ただし「45 億年を 38 分眺める」は退屈である

**面白い出来事は時間軸上に均等に分布していない。** 数億年何も起きず、
突然 LIP と大量絶滅が来る。速度段階だけでは足りない。

**「次の出来事まで進める」を主要な動詞にする。**

```
[▶▶ 次の出来事まで]
   LIP / テクトニクス様式の遷移 / 超大陸の集合・分散 /
   雪玉への突入・脱出 / 大量絶滅 / 能力の獲得
   が起きるまで最高速で進み、【自動で減速して停止】
```

併せて:

- 出来事が起きたら**自動で標準速度に落ちる**（見逃させない）
- タイムラインに**予測**を出す（「あと 3000 万年で LIP」）
- プレイヤーの介入が効くのは**遅い速度のときだけ**にする（緩急が生まれる）

これで「38 分ずっと眺める」ではなく
**「跳ぶ → 事件 → 対処 → 跳ぶ」**というリズムになる。
シムアースに無かった部分であり、寄与台帳（なぜ起きたかを分解して見せる）と噛み合う。

## 3.5 モード ★

**同じエンジンで、初期条件とイベント予約の強さだけを変える。** 別実装にはしない。

| | 地球進化モード | 自由進化モード |
|---|---|---|
| 初期条件 | 地球の実測値（冥王代 45.4 億年前） | 手続き生成 |
| 史実イベント | **予約する**（GOE 24 億年前、K-Pg 6600 万年前 …） | なし |
| ハードステップ（docs/02-2.1b） | 確率を上げる。見慣れた順序が出やすい | 基準確率のまま |
| 逸脱 | **する**。レールではなく「敷かれた轍」 | 全面的 |
| 生物の絵 | 既知クレードに一致したら手描きで上書き | 常に手続き生成 |

**地球モードでも逸脱を許すのが重要。** K-Pg で哺乳類ではなく鳥類が勝つ回があってよい。
そこが地球モードの遊びどころになる。「教科書をなぞるだけ」にすると
シムアースと同じ問題（何度遊んでも同じ）に戻る。

docs/02-1.6 の「地球の年表を比較トラックとして並走表示する」は両モードで使う。
自由進化モードでも「地球ではここで多細胞化した」が見えると、逸脱が読める。

## 3.5b シナリオ ★地球の地図は「初期条件」で与える

### シムアースはどうしていたか

シムアース（1990）は**プリセットのシナリオ**を用意していた
（Aquarium / Cambrian / Modern Day / Mars / Venus / Random）。
**「地球の地図」は初期条件として与えるもの**であり、計算で再現するものではない、
という割り切りである。プレイヤーは地形を直接編集する神の道具も持っていた。

**本作も同じ方針を採る。** 理由:

- プレート運動はカオスなので、**ランダムな初期状態から地球の地図に到達する確率はゼロ**
- 到達したらそれは物理計算ではなく再生である
- 冥王代の大陸配置は誰も知らない（そもそも与えられない）

### シナリオ一覧（案）

| シナリオ | 開始 | 性格 |
|---|---|---|
| **全史** | 冥王代 45.4 億年前 | 地図は毎回違う。「別の惑星の歴史」 |
| **パンゲア** | 2.5 億年前 | 見慣れた形から始まり、割れていく |
| **現代** | 現在 | 地球の未来。プレイヤーの介入で分岐 |
| ランダム惑星 | 任意 | 系外惑星 |

「地球そのものを目指しつつ、操作によって違う形になる」は
**シナリオ = 現代 / パンゲア**で自然に実現する。

パンゲアと現代の初期地形には地球の標高データ（ETOPO など）の取り込みが要るので、
**M7 が適切**。全史シナリオが先に完成している必要がある。

### ★シムアースとの決定的な違い — 大陸が痩せる failure mode

**シムアースは侵食も堆積収支もモデル化していなかった。**
地形は「押される」だけで、削られて海に流出することがない。
だから**大陸が痩せて消えることが構造的に起きなかった**。

本作は侵食・堆積・体積収支を計算している。その結果、
**収支のバランスがずれると大陸が消える**という、
シムアースには存在しなかった failure mode を持つ（docs/01-6.5c〜6.5e）。

> **シムアースで大陸が消えないのは、正しかったからではなく、その物理を持っていなかったから。**
> 持っている以上、合わせ込む責任がある。

### 地図の形は違ってよいが、統計は全シナリオで地球と一致すべき

| 指標 | 目標 | 2026-08-27 時点 |
|---|---|---|
| 陸地面積 | 25〜35% | **2.8%**（最終フレーム） |
| 陸の平均標高 | 800m 前後 | 300m |
| 最高標高 | 6000〜9000m | **876m**（山脈が一つも無い） |
| 大陸の数 | 数個 | — |

**これは物理が正しいかどうかの問題で、シナリオとは独立である。**
パンゲアから始めても、収支がずれたままなら 2.5 億年で痩せる。
**土台の収支を合わせてからシナリオを載せること。**

## 3.5c ★暗い太陽のパラドクスを「どの仮説で解いた惑星か」として遊ぶ

**現実の科学で解けていない問題を、シナリオの軸にする。**

40 億年前の太陽は現在の約 70%。それでも地球は凍っていなかった。
**仮説は 5 つあり、どれも決定打ではない**（`docs/06-2.2`）。
1 つを正解として焼き込むのではなく、**プレイヤーが選ぶ**。

### なぜこれが成立するか — 寄与台帳が既に答えを表示する

`core/ledger.ts` の `CAUSE_LABEL` は、そのまま仮説の一覧になっている:

```
solar / greenhouse.co2 / greenhouse.ch4 / geothermal /
albedo.cloud / antigreenhouse.haze
```

**「この惑星はどの仮説で凍らずに済んだか」は、太古代の寄与分解パネルを
見れば一目で分かる。** 説明する必要がない。見れば分かる。
docs/04-5 の台帳が【後から実装できない】と書かれている理由がここにも出る。

### 選択が「違う惑星」を作る（メニューではない）

| 仮説 | 惑星に何が起きるか | 生命への影響 | つまみ |
|---|---|---|---|
| **温室効果** | CO2 が桁で高い → 原生代に猛烈な引き下げ → 全球凍結のリスク | メタン生成菌が主役。ヘイズの自己制限と戦う | 脱ガス・風化 |
| **放射性熱** | マントルが熱い → 火山と海嶺が活発、海洋地殻が厚い、プレートが速い | **熱水噴出孔が桁で多い → 起源地が海底に** | 放射性核種の初期量 |
| **太陽が重い** | CO2 も CH4 も要らない → 大気が「退屈」 | ヘイズが無い。**生命は気候を支配しない** | `solarMultiplier` |
| **宇宙線・雲** | 気候が恒星の【活動】に左右される（光度ではなく） | **CCN（生物起源）と宇宙線が雲を奪い合う** | 恒星活動（未実装） |
| **潮汐加熱** | 月が近い → 自転が速い → コリオリが強い → **海洋循環が別物**、巨大な潮汐 | **潮だまりが起源地**。乾湿サイクルで重合 | 月の距離（未実装） |

### 特に良い 2 つ

**宇宙線・雲**は「雲を支配するのは生命か恒星か」という**直接の競合**を作れる。
生命が CCN を増やして雲を作り、恒星活動が宇宙線経由でそれを打ち消す。
**ガイア仮説の中心的な問い（生命は環境を制御しているか）を、
1 つの場の奪い合いとして表現できる。**

**潮汐加熱**は月の距離という 1 つのつまみが、潮汐加熱・自転速度・コリオリ・
潮汐の大きさを同時に動かす。海洋循環が別物になり、惑星の顔つきが根本から変わる。
しかも**潮だまりという別の起源地**が開く（`docs/02-2.8`）。

### 教育的な正しさ

**5 通り遊べば「この問題は解けていない」ことが体感で分かる。**
どれを選んでも惑星は成立するが、どれも決定的ではない——
それが現実の科学の状態そのもの。

**劣勢な仮説には確度マーク（🔴）を出したまま遊ばせること。**
`docs/06` の確度表記をそのまま UI に持ち込む。
「支持されていない説でも惑星は作れる」と正直に見せるほうが、
1 つを正解として教えるより science communication として強い。

### 設計上の含意

**3（太陽質量）だけが「星のパラメータ」で、他は「惑星のパラメータ」。**
地球の議論では劣勢な仮説でも、**系外惑星のシナリオでは主役になりうる。**
「任意のパラメータでも惑星がうまく動くか。地球はシナリオ」という
本作の目標からすると、**地球で否定された仮説こそサンドボックスの
つまみとして価値がある。** `solarMultiplier` が最初からつまみなのは、
この設計思想が入っていた証拠。

M7 のシナリオ機構（3.5b）と組み合わせる。

## 3.6 生物の絵 — 描くのではなく組み立てる ★

任意の形質の組み合わせに絵を用意するのは、素材を一枚ずつ描く発想では不可能である。
だが docs/02-2.0b でボディプランを**直交する軸**に分解してあるので、
**部品を軸で索引して手続き的に組み立てられる**。

```
体制 { 内骨格, 左右相称, 8 本の腕状付属肢, 閉鎖循環, 胎生 }
形質 { bodySize 0.6, brain 0.8, tempOptimum 0.3, ... }
        ↓ 決定論的に組み立て（同じクレードは常に同じ絵）
   胴体[内骨格・左右相称] + 付属肢[腕型]×8 + 感覚器[高brain] + 表面[裸] + 配色[寒冷]
```

**必要な素材数**:

| 部品 | 種類数 |
|---|---|
| 胴体コア（骨格 × 対称性 × 体節） | 8〜12 |
| 付属肢（腕 / 脚 / 鰭 / 翼 / 触手 / なし） | 約 10 |
| 頭部・感覚器（目の数・大きさ・複眼・なし） | 約 8 |
| 表面（鱗 / 毛 / 甲殻 / 裸 / 粘液） | 約 6 |
| 配色ランプ（惑星環境から導く） | 約 8 |

**合計 40〜50 個の部品で組み合わせは数万通り**になる。
「目が異常に発達した系統」は目パーツのスケールを形質値から引くだけ、
「腕が 8 本」は腕パーツを 8 回配置するだけ。

**ドット絵を採用する理由**（見た目の好み以上に、技術的にこの方式に向く）:

- 部品がグリッドにスナップするので**継ぎ目が出ない**。ベクターや 3D は接合部の処理が破綻する
- 限定パレットなので**配色の差し替えが安全**（惑星環境から色を決められる）
- 1 部品が小さいので、40〜50 個を手描きしても現実的な工数に収まる

**手描きは「上書き」であって「機構」ではない。**
地球の既知クレードに形質が一致したときだけ手描きスプライトを使い、
一致しなければ手続き生成に落ちる。これにより:

- 地球モードは見慣れた絵で読みやすい
- **逸脱した瞬間に手続き生成へ切り替わり、「見たことのない生き物になった」ことが絵で伝わる**
- 自由モードでも同じ描画エンジンが動く

決定論性の要件（docs/04-6）はここにも効く。
**同じクレードは常に同じ絵**になるよう、シードは形質ベクトルのハッシュから作る。

**プレイ後にこれを眺める時間がゲームの後味を決める。** 優先度は高い。

## 7. メタ進行 — 逐次選択の実装 ★

> **これが本作を SimEarth と最も強く分ける設計である。**

現代のガイア理論では、惑星の安定は目的ではなく**生存者バイアス**である（§00-2）。不安定な系は短命に終わり、**安定な配置に落ちたものだけが持続する**。

これをゲーム構造そのものに実装する。

### 7.1 試行の記録

敗北した惑星は消えない。**「試行 #n」としてアーカイブに記録される。**

```ts
interface Attempt {
  index: number
  seed: string
  finalYear: number
  endCondition: string        // '白い墓標' | '金星化' | ...
  peakAchievement: string     // 到達した最高段階
  phylogenyHash: string       // 系統樹の要約
  /** 次の惑星に残す痕跡 */
  legacy: Legacy
}
```

### 7.2 何が引き継がれるか

**能力の強化（ローグライク的な永続アップグレード）は入れない。** それは逐次選択の比喩を壊す。代わりに:

| 引き継ぐもの | 形 |
|---|---|
| **知識** | 過去の試行で観測した機構が、次の惑星の UI で最初から説明される。プレイヤー自身が学ぶ。ゲーム側は何も強化しない |
| **アーカイブ** | すべての試行の系統樹・タイムライン・敗因を並べて比較できる。**「試行の博物館」** |
| **地層の痕跡** ★ | 前の試行で産業文明が成立していた場合、次の惑星の地層に検出可能な異常が残る（§7.3） |
| **統計** | 「あなたの惑星のうち、モバイルリッドに遷移できたのは 7 個中 3 個」といった、逐次選択そのものの可視化 |

### 7.3 シルル紀仮説 🟡

Schmidt & Frank (2018) の思考実験:
> もし地球に数千万年前に産業文明があったとして、我々はそれを地質記録から検出できるだろうか？

**実装**: 前の試行で `energyCapture` が産業水準を超えていた場合、新しい惑星の堆積層に痕跡が埋め込まれる — 異常な炭素同位体比、合成物質、放射性核種、突然の花粉組成の変化。

新しい惑星で知的種が発生し、地質学を獲得すると、**それを発見する**。系統樹パネルとタイムラインに「先行文明の痕跡を発見」というマーカーが立つ。

新しい社会の `gaiaAwareness` は、この発見によって大きく上がる。**前の試行の失敗が、次の試行を救う。** これが逐次選択の、最も直接的なゲーム的表現になる。

### 7.4 なぜこれが正しいか

SimEarth では、失敗した惑星はただのやり直しだった。本作では**失敗そのものがメカニズムの一部**である。

> 環境を不安定化させる系は短命に終わり、絶滅と再編を経て、安定な配置に落ちたものだけが持続する。
> — Lenton et al. 2018

プレイヤーは一つの惑星の神ではなく、**多数の試行を通じて安定配置を探索する過程そのもの**を演じている。
