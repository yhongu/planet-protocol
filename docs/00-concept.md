# 00. コンセプト

> **前提**: 本作の科学的な立脚点は [06-science-basis.md](06-science-basis.md) にまとめてある。
> SimEarth (1990) の科学は多くが更新されており、本作はその 35 年分の改訂を織り込んだ設計を採る。

## 1. 一行で

**惑星が自己調節系になれるかどうかを、何度も試す。**

「ガイアを作るゲーム」ではない。ガイアは**達成されるとは限らない**。生命はしばしば惑星を殺す。安定した惑星とは、**壊れなかった試行のこと**である。

## 2. なぜこの一行なのか — ガイア仮説は 1990 年から変わった

SimEarth はラヴロックの**強いガイア仮説**（惑星は生命によって目的的に自己調節される超個体である）を機構化したゲームだった。当時の最良の科学であり、CLAW 仮説という実例もあった。

現在:

- **強いガイアは否定されている。** 惑星スケールには自然選択の単位が存在しない。
- **CLAW 仮説は実測で支持されなかった** (Quinn & Bates 2011)。1990 年当時の最有力事例が消えた。
- 代わりに有力なのが **逐次選択 (sequential selection)** — Lenton et al. 2018:
  > 環境を不安定化させる系は短命に終わり、絶滅と再編を経て、安定な配置に落ちたものだけが持続する。
  > 持続した系だけが、さらに安定性を高める性質を獲得する時間を得る。
- そして正反対の主張として **メデア仮説** (Ward 2009) — 生命は本質的に自殺的であり、大量絶滅の多くは生物自身が引き起こした。

**つまりガイアは目的ではなく生存者バイアスである。**

これは失望ではなく、**ゲームデザイン上の大幅な改善**である。1990 年の「生命は惑星を安定させる」は所与の前提であり、ゲーム的な緊張を持たない。2026 年の「安定は勝ち取られるか、さもなくば消える」は**そのままゲームのルール**になる。

## 3. 原典の分析

### SimEarth が偉大だった点

- 地質・大気・生命・文明という、通常は別ジャンルになる 4 つの時間スケールを 1 画面に同居させた。
- 生物が環境を変え、環境が生物を選別する閉ループを、はじめてゲーム機構にした。
- 惑星規模の思考を娯楽にできると証明した。

### SimEarth が失敗していた点（＝本作が直すべき点）

| 問題 | 原因 | 本作の対処 |
|---|---|---|
| **何をすればいいか分からない** | 明示的な目標が薄い | 段階的な達成条件 + シナリオ制（§03） |
| **因果が読めない** | 内部モデルは精緻だが UI が結果しか見せない | **寄与分解パネル**を目玉機能に（§03-5.3） |
| **待ち時間が長い** | 全サブシステムが同一ティックで回る | **エポック別ティックレート**（§01-1） |
| **介入のコストが軽い** | エネルギー予算が惑星状態と切り離されていた | **Ω は惑星の恒常性の関数**（§03-2） |
| **生命が装飾的** | 種の分岐がプレイヤー操作依存 | 形質ベクトル × 環境適合度による自律的な適応放散（§02） |
| **一度きりのプレイで終わる** | 失敗した惑星に意味が無い | **逐次選択をメタ進行として実装**（§4 柱1、§03-7） |

### 1990 年の科学に依存していた設計（＝作り直す点）

| SimEarth の設計 | 現在の科学 | 本作 |
|---|---|---|
| 生命 = 惑星の安定化装置 | 生命は安定化も破壊もする（メデア仮説） | 両方を同じ機構から出す（§02） |
| 進化は一本のはしご | 多細胞性は 25 回以上独立に進化。人類も braided stream | **グレードは到達領域であり、何度でも独立に到達される**（§02-2） |
| 3 ドメインの生命樹 | 二ドメイン説。真核生物はアーキア内部から内部共生で誕生 | **系統樹に合流 (reticulation) を実装**（§02-2.4） |
| 風化サーモスタットは常に効く | 供給律速レジームでは壊れる (Maher & Chamberlain 2014) | **山があるときだけサーモスタットが効く**（§01-4.2） |
| 暗い太陽はメタン温室で解決 | ヘイズの反温室効果で自己制限。複合要因 | N₂ 分圧・ヘイズ・雲凝結核まで実装（§01-3.3） |
| プレートテクトニクスは常在 | 開始時期は 4.0–0.7 Ga で係争中。太古代は別様式 | **テクトニクス様式を時間発展する状態変数に**（§01-6.1） |
| 文明は技術の階段を上る | 農耕は 11 箇所で独立発生、放棄もされた。段階論は否定的 | **生業ミックス × エネルギー捕捉量の多次元状態**（§02-4） |
| 崩壊 = 文明の消滅 | 崩壊の多くは再編。ラパ・ヌイのエコサイドは否定された | **崩壊 = 規模と階層性の低下、知識は残る**（§02-4.5） |
| 大量絶滅 = 災害イベント | ビッグファイブの 4 つは LIP 由来。殺傷機構の連鎖が特定済み | **因果連鎖をそのまま実装**（§02-3.4） |

## 4. 差別化の核 — 4 本の柱

### 柱 1: ガイアは勝ち取られるか、さもなくば消える

惑星の恒温性は所与ではない。プレイヤーは炭素循環の負のフィードバックを成立させ、それを支える造山活動を維持し（§01-4.2）、酸素供給を確立し、それらが噛み合って初めて「惑星が自分で温度を戻す」ようになる。

そして **恒常性は状態ではなく履歴で判定する。** 「N 回の擾乱を受けて、その都度回復した」という実績でのみ認定される。逐次選択の実装。

**失敗した惑星は捨てられない。** 敗北した惑星は「試行 #n」として記録され、次の惑星に痕跡を残す（§03-7）。プレイヤーは一つの惑星の神ではなく、**多数の試行を通じて安定配置を探索する過程そのもの**を演じる。

### 柱 2: 因果が見える

すべての状態変化は**寄与の内訳**を持つ。

```
ΔT = +3.2℃
  ├ 温室効果 (CO₂ 280→410ppm)   +1.8
  ├ 氷アルベド後退              +1.1
  ├ 植生アルベド (森林→草原)     +0.5
  ├ 有機ヘイズの反温室効果       -0.3
  └ 海洋熱吸収                  +0.1
```

大量絶滅も同じ形式で読める。ペルム紀末の「LIP → 温暖化 → 成層化 → 貧酸素 → 硫化 → 毒化」という連鎖（§02-3.4）が、寄与台帳の上で一段ずつ表示される。**災害が読み物になる。**

### 柱 3: 生命は味方とは限らない

- **後期デボン紀**: 陸上植物が根系で大陸を風化させ、栄養塩が海に流入し、富栄養化 → 貧酸素 → 海洋の大量絶滅。**生命が生命を殺した。**
- **Lomagundi 事変の終焉**: 一次生産の暴走が栄養を枯渇させ、自らを崩壊させた。
- **大酸化事変**: シアノバクテリアの成功が、それまでの嫌気性生物圏を壊滅させた。

これらはすべて同じ機構（形質 × 環境フィードバック）から自然に出る。**特別な「災害」コードは書かない。** プレイヤーが育てた生命が、プレイヤーの惑星を壊す。

### 柱 4: 文明は共犯者であり、継承者である

知的種は惑星の恒常性を破壊する最大の要因だが、同時に**恒常性を自覚的に維持できる唯一の存在**でもある（Lenton & Latour 2018 の "Gaia 2.0"）。

終盤の課題は「文明を滅ぼす」でも「文明を守る」でもなく、**文明にガイアの管理者を継がせる**こと。
ただしこの文明は技術の階段を上らない。生業を選び、放棄し、集約し、分散する。崩壊しても消えない。**進歩ではなく、選択の連続として描く。**

## 5. トーン

- 視点は**惑星スケール**。個体や都市は点、あるいは統計量。
- 演出は静か。派手なエフェクトより、レイヤを切り替えたときのデータの美しさで見せる。
- 時間の重さを感じさせる。45 億年を数時間で通す以上、「10 万年が一瞬で溶ける」感覚は失わない。
- **科学的な誠実さをトーンの一部にする。** 係争中の論点（§06 の 🔴）は、断定せずスライダーとして露出させる。「これは分かっていない」と言うことがゲームの魅力になる。

## 6. スコープの前提

| 項目 | 決定 |
|---|---|
| プラットフォーム | Web（TypeScript + Canvas/WebGL） |
| マップ形状 | 平面グリッド、東西ループ、南北は極（緯度あり） |
| 標準グリッド | 256 × 128（可変。開発時は 128 × 64） |
| 対象 4 系 | 地質 / 気候 / 生命 / 文明 — すべて実装対象 |
| プレイ時間 | 1 シナリオ 1〜3 時間。サンドボックスは無制限 |
| メタ進行 | あり（試行の記録が次の惑星に引き継がれる） |
| マルチプレイ | 対象外 |
